# T2. 甜筒的路径

### code1

单次询问 $O((n-2)!)$。

直接爆搜。

具体的，每次搜 $2$ 步 ($1$ 个回合)，如果搜到已经经过的"整回合点"就剪枝。

枚举排列即可，需要提前处理出点对的整回合可达性。

精细实现 ($s,t$ 的位置确定)，就可以 $O(q \times (n-2)!)$。

预计开 $n \le 10,m \le n^2+n,q \le 100$。

### code2

单次询问 $O(2^nn^2)$。

状压 DP。

借助 **code1** 的思路，记录 $f_{S,x}$ 表示集合 $S$ 中的点被经过，当前在 $x$，这个状态是否可以被到达。

转移是 $O(n)$ 的。

预计开 $n \le 15,m \le n^2+n,q \le 100$。

### code3

单次询问 $O(n^3)$。

发现 **code2** 记录 $S$ 太没必要了。

发现记录 $S$ 的本质是转移没有环。

那么把 $S$ 改成 $c \in [0,n]$ 即可。

预计开 $n \le 100,m \le n^2+n,q \le 100$。

### code4

单次询问 $O(n^2)$。

发现 **code3** 记录 $c$ 也是不必要的。

问题的关键只在于能否从 $s$ 到达 $t$。

只需要从 $s$ 开始 bfs。

---

其实上面的做法等价于 :

对于每个点 $u$，遍历邻点 $v,w$，如果 $v \rightarrow u \rightarrow w$ 可以作为整个回合，就在新图上连边 $v \rightarrow w$。

预计开 $n \le 500,m \le n^2+n,q \le 500$。

### code5

预处理 $O(nm \alpha (n))$，单次修改 $O(n+\alpha (n))$，单次查询 $O(\alpha (n))$。

总时间复杂度 $O(n(m+q) \alpha (n))$。

发现 **code4** 建出来的图是无向图。

所以跑 DSU 就可以。

动态维护加入 DSU 的边。

加边是暴力的，直接遍历邻点。

预计开 $n \le 2000,m \le 10^4,q \le 10^4$。

### code6

总时间复杂度 $O((m+q) \alpha (n))$。

发现不用 **code5** 这么暴力的加边。

以下只讨论加边的情况 (且只考虑 $u'$ 的情况)，预处理同理。

如果 $w'=0$ :

- 那么可以连接 $u'$ 的所有邻点。
  
- 如果 $u'$ 已经有 $0$ 邻边，那么只需 DSU 合并任意 $1$ 个邻点，否则全部合并。
  
- 这部分总时间复杂度 $O((m+q) \alpha (n))$ (均摊)。
  

如果 $w'=1$ :

- 只能连接 $u'$ 的 $0$ 邻点。
  
- 只需连接任意 $1$ 个 $0$ 邻点 (如果存在 $0$ 邻点，所有邻点就已经连通)。
  
- 这部分时间复杂度 $O((m+q)\alpha (n))$。
  

---

注意到原问题的限制可以等价放缩为 :

- $2 \nmid k$。
  
- $\forall 1 \le i \le k$ 且 $2 \nmid i$，点 $p_i$ 至少存在 $1$ 个 $0$ 邻点。
  

必要性显然。

充分性就是考虑用 $0$ 邻点过渡。

考虑分层图，对于 $i$ 的奇偶性讨论 :

- 若 $u$ 有 $0$ 邻边，则可以从 $(u,0)$ 连向 $(v,1)$。

判断 $s,t$ 是否连通即可。

加边就是如果某个点从无 $0$ 邻边变成有 $0$ 邻边，就把积压的边都连上。

总时间复杂度 $O((m+q) \alpha (n))$。

朴素实现是 $O(n(m+q) \alpha (n))$。

预计开满。

### 关于特殊性质

特殊性质 $\text{A}$ : 没有操作 $1$。

特殊性质 $\text{B}$ : 所有操作 $1$ 满足 $w'=0$。

特殊性质 $\text{C}$ : 所有操作 $1$ 满足 $w'=1$。

特殊性质 $\text{D}$ : 所有 $w_i=0$。

特殊性质 $\text{E}$ : 所有 $w_i=1$。

特殊性质 $\text{F}$ : 给定的无向图是森林。

特殊性质 $\text{G}$ : 所有 $|u_i-v_i|=1$ 且所有操作 $1$ 满足 $|u'+v'|=1$。

在满数据范围下 :

- $\text{A}+[q=1]$ : 只会单次 $O[n,n^2)$ 判断。
  
- $\text{A}$ : 不会维护加边的，单次 $O(\alpha)$。
  
- $\text{B}$ : 只会加 $0$ 边 (全都激活)。
  
- $\text{C}$ : 只会加 $1$ 边 (不改变激活性)。
  
- $\text{AD}$ : 静态判断每个块是否有奇环 (DSU 维护二分图)。
  
- $\text{BD}$ : 动态判断每个块是否有奇环 (DSU 维护二分图)。
  
- $\text{CE}$ : 答案为 ```No``` (除非 $s=t$)。
  
- $\text{AF}$ : 只会静态树上问题 (大部分只需要判断到 $u \rightarrow f_{f_u}$ 的合法性)。
  
- $\text{ADG}$ : 直接判连通性和奇偶性。
  
- $\text{AG}$ : 静态链 (前缀和)。
  
- $\text{BDG}$ : 动态判连通性和奇偶性。
  
- $\text{G}$ : 动态链 (树状数组/线段树)。
