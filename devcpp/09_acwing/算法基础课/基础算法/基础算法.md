# 排序

## [快速排序](https://www.acwing.com/problem/content/787/)

题目要求就是给数组排序，没啥好讲的。

快速排序通常明显比其他 $Ο(n\log n)$ 算法更快，因为它的内部循环可以在大部分的架构上很有效率地被实现出来。快速排序的基本思想是：通过一趟排序将待排记录分割成独立的两部分，其中一部分记录的关键字均比另一部分记录的关键字小，则可分别对这两部分记录继续进行排序，已达到整个序列有序。一趟快速排序的具体过程可描述为：从待排序列中任意选取一个记录作为基准值，然后将记录中关键字比它小的记录都安置在它的位置之前，将记录中关键字比它大的记录都安置在它的位置之后。这样，以该基准值为分界线，将待排序列分成的两个子序列。它是处理大数据最快的排序算法之一了。该算法时间复杂度为 $Ο(n\log n)$。

快速排序算法的原理如下：

- $1$、从数列中挑出一个元素，称为 “基准”（pivot）;

- $2$、重新排序数列，所有元素比基准值小的摆放在基准左边，所有元素比基准值大的摆在基准的右边（相同的数可以到任一边）。在这个分区退出之后，该基准就处于数列的中间位置。这个称为分区（partition）操作；

- $3$、递归地（recursive）把小于基准值元素的子数列和大于基准值元素的子数列排序。

代码如下：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 快速排序
void QuickSort(int arr[], int start, int end) {
	if (start >= end) return; //分完了 
    int i = start, j = end, pivot = arr[(start + end + 1) / 2]; //基准数
    while (i <= j) {
		while (arr[i] < pivot) i++; //从左向右找比基准数大的数
        while (arr[j] > pivot) j--; //从右向左找比基准数小的数
        if (i <= j) swap(arr[i++], arr[j--]); //进行交换
    }
	//分成两个子序列接着进行快速排序 
	if(start < j) QuickSort(arr, start, j); //遍历左边 
	if(i < end) QuickSort(arr, i, end); //遍历右边 
}

int len, arr[100010];
int main() {
	cin >> len;
	for (int i = 1; i <= len; i++)
		cin >> arr[i];
	QuickSort(arr, 1, len);
	for (int i = 1; i <= len; i++)
		cout << arr[i] << " ";
	return 0;
}
```

## [第k个数](https://www.acwing.com/problem/content/788/)

可以使用快速排序之后进行查询第 $k$ 个数，时间复杂度为 $O(n\log n)$

不过我们在快速排序的时候，当快速排序结束后，那么就分成两个区间了，之后我们再选择其中一个区间(包含第 $k$ 个数)接着进行快速排序就行了。

代码如下：

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int read() {
	int x = 0, f = 1;
	char ch = getchar();
	while(ch < '0' || ch > '9') f *= (ch == '-' ? -1 : 1), ch = getchar();
	while(ch >= 48 && ch <= 57) x = (x << 1) + (x << 3) + (ch ^ 48), ch = getchar();
	return x * f;
}

int n, k, a[maxn];
void qsort(int l, int r) {
	int i = l, j = r, pivot = a[(l + r + 1) / 2];
	while(i <= j) {
		while(a[i] < pivot) i++;
		while(a[j] > pivot) j--;
		if(i <= j) swap(a[i++], a[j--]);
	}
	if(k >= i) qsort(i, r);
	else if(k <= j) qsort(l, j);
	else return ;
}

signed main() {
	cin >> n >> k;
	for (int i = 1; i <= n; i++) a[i] = read();
	sort(a + 1, a + n + 1); 
	cout << a[k] << endl;
//	for (int i = 1; i <= n; i++) cout << a[i] << " ";
	return 0;
}
```

## [归并排序](https://www.acwing.com/problem/content/789/)

题目要求就是给数组排序，没啥好讲的。

归并排序是建立在归并操作上的一种有效的排序算法。该算法是采用分治法（Divide and Conquer）的一个非常典型的应用。将已有序的子序列合并，得到完全有序的序列；即先使每个子序列有序，再使子序列段间有序。代价是需要额外的内存空间。若将两个有序表合并成一个有序表。 该算法时间复杂度为 $O(nlogn)$。

归并排序算法的原理如下：

- $1$、把长度为 $n$ 的输入序列分成两个长度为 $\frac{n}{2}$ 的子序列；

- $2$、对这两个子序列分别采用归并排序；

- $3$、将两个排序好的子序列合并成一个最终的排序序列。

代码如下：


```cpp
#include <iostream>
#include <cstdio>
using namespace std;

// 归并排序
int temp[1010]; //辅助空间 
void MergeSort(int arr[], int start, int end) { //start和end分别是左边界和右边界
	if (start >= end) return;
	int mid = (start + end) / 2, i = start, j = mid + 1;
	MergeSort(arr, start, mid); //分成两个子序列 
	MergeSort(arr, mid + 1, end);
 
	// 合并两个有序序列
	int k = 1; // 表示辅助空间有多少个元素
	while (i <= mid && j <= end) {
		if (arr[i] < arr[j]) temp[k++] = arr[i++];
		else temp[k++] = arr[j++];
	}
	while (i <= mid) temp[k++] = arr[i++]; //把剩下数的合并
	while (j <= end) temp[k++] = arr[j++]; //同上 
	// 把辅助空间的数据放到原空间
	for (int i = start; i <= end; i++)
		arr[i] = temp[i - start + 1];
}

int len, arr[1010];
int main() {
	cin >> len;
	for (int i = 1; i <= len; i++)
		cin >> arr[i];
	MergeSort(arr, 1, len);
	for (int i = 1; i <= len; i++)
		cout << arr[i] << " ";
	return 0;
}
```

## [逆序对的数量](https://www.acwing.com/problem/content/790/)

这道题其实与[这题](https://www.luogu.com.cn/problem/P1116)差不多，只不过因为这题的 $n \le 100000$，所以难度也增加了，那该怎么办呢？

首先，让我们先想想暴力该怎么写。

由于这道题是让我们求出需要交换多少次，而每次交换相邻两个数以达到元素有序的排序是什么呢？让我们想想！

- 选择排序，不对（这是每次与第一个元素交换的排序）
- 插入排序，不对（这是每次插入到前面某个点的排序）
- 计数排序，不对（这不是交换类型的排序）
- 桶排序，不对（这是混合类型的排序）
- 基数排序，不对（这不是交换类型的排序）
- 快速排序，不对（这是两个元素交换位置不确定的排序）
- 希尔排序，不对（这是两个元素交换不一定相邻的排序）
- 堆排序，不对（这是交换父节点和子节点的排序）

想来想去，似乎都没有，那到底是什么排序呢？

聪明的你应该看出来了吧！这就是

> # 冒泡排序！

那么思路就很清晰了，每次如果 $a_j > a_{j+1}$，那么 $ans+1$，并且交换这两个元素就好了。

上代码（请注意，这是 $77$ 分的代码）：

```cpp
#include <bits/stdc++.h>
#define maxn 500010 
using namespace std;

int n, a[maxn];
long long ans;
int main() {
	scanf("%d", &n);
	for (int i = 1; i <= n; i++)
		scanf("%d", &a[i]);
	for (int i = 1; i < n; i++) //冒泡排序遍历n-1次 
		for (int j = 1; j <= n - i; j++) //开始遍历每个元素
			if(a[j] > a[j + 1]) ans++, swap(a[j], a[j + 1]); //如果发现a[j] > a[j + 1]，那么交换两个数的值，并且ans++; 
	printf("%d\n", ans);
	return 0;
}
```

很明显，虽然我们思路是对的，但是由于冒泡太慢了，导致最后两个点过不了，那该怎么办呢？

再看看我们上面分析的，数一数，我们已经判断完了十大排序中的九大排序，那还有一个排序是什么呢？

聪明的你又会发现了，这就是

> # 归并排序！

找到了最后的救命稻草之后，我们想一想，如何用归并排序巧妙的解这道题呢？

由于不知道该怎么分析，那我们先把归并排序的思路摸索一遍。

- 首先，先分治（手玩一下样例）

![](https://cdn.luogu.com.cn/upload/image_hosting/svl3g8aj.png)

- 之后，进行合并。但是，应该怎么合并呢？

我们可以进行分析，定义一个变量 $mid = \frac{l + r}{2}$，再定义两个指针 $i = l$ 和 $j = mid + 1$，$i$ 负责遍历左子树，$j$ 负责遍历右子树。在一些基本的工作做完之后，我们就要来合并了。

那么如何合并呢？我们分两种情况讨论：

1. $arr_i < arr_j$，那什么事情都不用干（因为 $arr_i$ 本身就在左边，所以不需要 $ans$ 记录），直接把 $arr_i$ 放入临时数组里面就可以了。
2. $arr_i \ge arr_j$，那么就代表要把 $arr_j$ 进行挪动（因为 $arr_j$ 在右边），需要用到 $ans$ 了。那么挪动多少呢？我们还是可以画图想想：
   刚开始时是这样![](https://cdn.luogu.com.cn/upload/image_hosting/vovvxlqn.png)
   之后发现 $0 < 4$，把 $0$ 加入 $temp$ 数组里![](https://cdn.luogu.com.cn/upload/image_hosting/28yhrnbo.png)
   接着 $i+1$，又发现 $1 < 4$，把 $1$ 加入 $temp$ 数组![](https://cdn.luogu.com.cn/upload/image_hosting/ty2jdr25.png)
   接着 $i+1$，发现 $9 \ge 4$，则 $4$ 加入 $temp$ 数组里。而这时候，$4$ 应该移动位置了，那么移动多少呢？很明显需要移动 $1$ 个位置，那为什么是移动一个位置呢？因为剩下左边元素的数量是 $1$。所以，我们可以推出，如果 $arr_i \ge arr_j$，则 $ans + (mid - i + 1)$ ![](https://cdn.luogu.com.cn/upload/image_hosting/c8kha684.png)
   接着 $j+1$，发现 $9 \ge 5$，则 $5$ 加如 $temp$ 数组里。之后 $ans + (mid - i + 1)$。
   ![](https://cdn.luogu.com.cn/upload/image_hosting/ylnmu32p.png)
   接着 $j+1$，可以发现 $j > r$，则退出。并且把 $9$ 加入末端。
   ![](https://cdn.luogu.com.cn/upload/image_hosting/srmgyhzk.png)
   接着 $i+1$，算法结束。
   当我们发现如果 $arr_i \ge arr_j$，则 $ans + (mid - i + 1)$ 这个公式之后，问题就随之迎刃而解了。

上代码（这次是真 AC）：

```cpp
#include <bits/stdc++.h>
#define maxn 500010
using namespace std;

//归并排序
long long ans;
int len, arr[maxn], temp[maxn]; //辅助空间 
void MergeSort(int arr[], int start, int end) { //start和end分别是左边界和右边界
	if (start >= end) return;
	int mid = (start + end) / 2, i = start, j = mid + 1;
	MergeSort(arr, start, mid); //分成两个子序列 
	MergeSort(arr, mid + 1, end);
 
	// 合并两个有序序列
	int k = 1; // 表示辅助空间有多少个元素
	while (i <= mid && j <= end) {
		if (arr[i] < arr[j]) temp[k++] = arr[i++]; //没有产生逆序对
		else ans += mid - i + 1, temp[k++] = arr[j++]; //如果产生了逆序对，则答案加上左边剩余元素个数
	}
	while (i <= mid) temp[k++] = arr[i++]; //把剩下数的合并
	while (j <= end) temp[k++] = arr[j++]; //同上 
	// 把辅助空间的数据放到原空间
	for (int i = start; i <= end; i++)
		arr[i] = temp[i - start + 1];
}


int main() {
	cin >> len;
	for (int i = 1; i <= len; i++)
		cin >> arr[i];
	MergeSort(arr, 1, len);
	cout << ans << endl;
	return 0;
}
```

## [数的范围](https://www.acwing.com/problem/content/791/)

如果使用暴力枚举，每次都跑一遍，那么时间复杂度为 $O(qn)$，不能通过此题。

我们可以发现，我们的暴力忽略了题目中的一句话：

> 给定一个按照升序排列的长度为 $n$ 的整数数组

是的，由于每次我们都可以先猜一个位置 $i$，如果 $a_i>k$，则往前面找，否则记录答案，并且往后面找，这样就确定右边界了。

反之，左边界也一样。

代码如下：

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, q, k, a[maxn];
int left(int x) { //左边界
	int l = 1, r = n, ans = -1;
	while(l <= r) {
		int mid = (l + r) / 2;
		if(a[mid] == x) ans = mid, r = mid - 1; //由于是要找左边界，所以当a[mid] == x时，要往左边找
		else if(a[mid] < x) l = mid + 1;
		else r = mid - 1;
	}
	return ans;
}

int right(int x) { //右边界
	int l = 1, r = n, ans = -1;
	while(l <= r) {
		int mid = (l + r) / 2;
		if(a[mid] == x) ans = mid, l = mid + 1;  //由于是要找左边界，所以当a[mid] == x时，要往右边找
		else if(a[mid] < x) l = mid + 1;
		else r = mid - 1;
	}
	return ans;
}

signed main() {
	cin >> n >> q;
	for (int i = 1; i <= n; i++) cin >> a[i];
	while(q--) {
		cin >> k;
		int l = left(k), r = right(k);
		if(l == -1 && r == -1) cout << "-1 -1" << endl; //没找到
		else cout << l - 1 << " " << r - 1 << endl;
	}
	return 0;
}
```

## [数的三次方根](https://www.acwing.com/problem/content/792/)

考虑 $x$ 越大，则 $x^3$ 越大；$x$ 越小，则 $x^3$ 越小。有明显的单调性，因此使用二分答案。

不过要注意有浮点数问题，所以二分边界不应当为`l <= r`，而应该是`r - l > 1e-8`

代码如下：

```cpp
#include <bits/stdc++.h>
#define eps 1e-8
using namespace std;

long double n;
signed main() {
	cin >> n;
	double l = -10000, r = 10000;
	while(r - l > eps) {
		double mid = (l + r) / 2;
		if(mid * mid * mid < n) l = mid;
		else r = mid;
	}
	printf("%.6f", l);
	return 0;
}
```

# 高精度

## [高精度加法](https://www.acwing.com/problem/content/793/)

### `int`的悲伤与高精度的需求

> 我们往常在作运算的时候，往往直接用运算符完成运算（譬如 $a + b$）。这当然非常地简便。
>
> 但是当**数据范围特别大**的时候，你去用运算符做加法往往得不到正确的结果，**为什么？？**
>
> 首先，在`c++`里，每一种实数变量型都是有一个数据储存范围的。**譬如`int`型，它的数据范围就为 $−2147483648\le\text{int}\le2147483647$。一旦你给一个`int`型变量存一个大于这个范围的数，它就会产生溢出，然后你存的数字会变成另外一个非常神奇的数字** 。可以自己在线下试一试哦。
>
> ~~不要和我提Python和java！~~
>
> 这个时候，你存的数字本身就已经发生错误，就不用指望他来运算了。
>
> 当然也有解决办法，譬如开`long long`。但是当数据范围高到恐怖的地步的时候（甚至大于 $101000101000$），别说 `longlong` 了，开挂神器 `__int128` 都救不了你。
>
> 这个时候，就需要高精度算法来解决问题。

### 数组搞定高精度

上面我们有提到过，在数据范围很大的时候，任何变量型已经无法满足我们的需求。这个时候怎么办？

接下来介绍一种最传统的做法：开数组。

我们开一个数组。这个数组开到多大？就要看你要存的数的位数有多少。若想存一个 $2000$ 位的数，就把数组开到 $2000$ 以上。

你位数可以多啊，你多一位 位数，我就把数组多开一个空间。~~看谁斗得过谁~~

而本题甚至开到了 $100000$ 位，所以我选择把数组开到 $100010$ 位。（开多点没坏处）

**想必这样说大概都清楚了。我们用数组的每一个空间来存每一位数的那个数字。**

这句话是什么意思呢？我们打个比方。

比如说我们现在要存 $123$ 这个数，把它存进 $a$ 数组里。

我们可以取出最后一位（个位）$3$，放到 $a_1$ 中。于是 $a_1 = 3$

同理，我们取出 $2,1$ 放进数组，于是就有：

```cpp
a[1] = 3;
a[2] = 2;
a[3] = 1;

//也就是: a[MAXN] = {3, 2, 1};
```

**此时，$a_i$ 就代表了此数的最后 $i$ 位**

$\large\text{但是}$

**我们并不选择直接一个一个输入每位数字，把数字存进数组。**

我们选择使用**字符串** ，像这样：

```cpp
string s, t;
cin >> s >> t;
for (int i = 1; i <= s.size(); i++) a[i] = s[s.size() - i] - '0';
for (int i = 1; i <= t.size(); i++) b[i] = t[t.size() - i] - '0';
//这个代码底下有解释
```

**为什么这样做？**

首先，**字符串输入两个数字，我们可以直接地知道每个数字的长度，也就是位数**（字符串 $a$ 的长度为 $a.size()$，依次类推）。**知道长度就可以直接给 `for` 循环服务。**

其次，字符串它输入方便啊，一个 `cin` 就完成了，也不必去检验什么输入到空格之类的了。

当然，最方便的是可以将字符串扔进子函数里（这个在最后有拓展）

**当然：将字符串转化进数组需要一定技巧：**

1. 首先，字符串里同样可以用下表形式表示某位的数（譬如 $s_i$），**但是和我们之前的存法相反，$s_0$ 表示的数字的最高位，次高位是 $s_1$。他是从 $0$ 且是从高位算起的，和我们之前说的从低位开始存恰好相反。**

2. 其次，字符串里每个数其实都是 `char` 型的。虽然看起来和 `int` 型没什么不同，**但是想把 `char` 型转化成 `int` 型需要通过一个介质：`ASCII` 码。**

每个 `char` 字符都有对应的 `ASCII` 码，而 $0\sim 9$ 的 `ASCII` 码是 $48\sim 57$。**如果你尝试把一个 `char` 型的 $0$ 存进 `int`，那么存进去的则是 $0$ 的`ASCII`码，也就是 $48$。**

这两个情况怎么解决？

1. **第一个问题，我们只需要把数组的第 $i$ 位和字符串的第（位数 $−i$）位对应起来就可以了。这是很好证明的。**

假设我们要存一个 $3$ 位数，它的每一位：

用数组表示：$a_1,a_2,a_3$

用字符串表示：$s_{3-1},s_{3-2},s_{3-3}$**（这里千万要注意字符串下标是从 $0$ 开始存的，也就是 $s_0$ 表示最高位）**

代码中手打出来就可以了。

2. 第二个问题，$0\sim 9$ 的 `ASCII` 码不是 $48\sim 57$ 么，那么把字符引入 `int` 型的时候，**我们只需要引入时把每个数减去 $48$ 就行了。** $48\sim 57$ 减去 $48=0\sim 9$ 道理都懂，对吧。

**当然你可以把 $48$ 写成 `′0′`。`′0′` 就代表着 $0$ 的 `ASCII` 码**

**于是这就有了我上面给出的代码：**

```cpp
string s, t;
cin >> s >> t;
for (int i = 1; i <= s.size(); i++) a[i] = s[s.size() - i] - '0';
for (int i = 1; i <= t.size(); i++) b[i] = t[t.size() - i] - '0';
```

**于是乎，我们就有了两个数组，存了两个高精度数字**

### 小学计算教你做加法

**数字存进数组去了，那么问题来了，如何让两个数组作加法？？**

答案很简单：**小学竖式运算！**

~~什么？你居然教我加法用竖式？？？~~

好吧，可能各位做加法熟能生巧，不需要列竖式就可以口糊出来。但是你要知道，计算机并不会做数组相加的运算。于是我们就需要“教他”算。

小学老师怎么教你算加法？当然是竖式运算。

具体做法就是：**把两个数字的每一位对齐，从低位到高位，同一位逐次相加，如果加的和大于十就向前进一位。**

计算机的竖式运算同样是这个道理。我们假设有两个存了数字的数组 $a,b$。

我们把两个数的每位对齐，刚刚我们提到：$a_i$ 代表 $s$ 这个数的第 $i$ 位。同理：$b_i$ 代表 $t$ 这个数的第 $i$ 位。

**那么，我们只需要做的就是 $a_i+b_i$就行了。这就代表了 $s$ 的第 $i$ 位减去了 $t$ 的第 $i$ 位**

我们用表格演示一下 $114514$ 加上 $765432$，其中，$ans$ 数组用来存储答案
$$
114514\\
765432\\
\tiny------\\
879946
$$
可以看到，每一位依次相加，最后传进答案数组，这个相减的过程就完成了。

用代码表示，可以表示成：

```cpp
ans[i] = a[i] + b[i];
```

$\Huge \text{可是！以上问题没有考虑过进位的情况！}$

如果要进位，我们怎么处理？？

根据小学竖式~~的博大精深~~来看，我们可以先加完，然后再向高位进位。

这个**进位**如果要说明白点，就是高位加上一个 $1$，之后低位再减去一个 $10$。

具体的，如果运算 $34+19$，$4+9$ 明显超过十，于是：

>$34 + 19 = (30 + 4) + (10 + 9) = (40 + 13)
>= 50 + 3 = 53$

上面的例子中，十位很明显的进了 $1$，之后各位又减去 $10$，然后 $50+3$ 进行运算

这个东西放到我们数组相加也适用。**简单来说，当一位加另一位的和超过十时，就从高位进 $1$，之后这一位的和就减去 $10$，当然高一位的和要加 $1$**。

我们再用表格举个例子：$456789+147791$
$$
456789\\
147791\\
\tiny------\\
604580
$$
这样就成功处理了进位的问题。

用代码就这样表示：

```cpp
int maxl = max(a.size(), b.size()) + 1; //有可能有进位，因此要+1
//找到两个数中的最大位，为for循环服务 
//如果两个数位数不相等，相加也无妨，因为位数少的数那部分被0补齐，加下去不影响
for (int i = 1; i <= maxl; i++) {
	if(ans[i] + a[i] + b[i] >= 10) { //要进位
		ans[i + 1]++; //向前+1
        ans[i] += a[i] + b[i] - 10; //进位
	} else ans[i] += a[i] + b[i]; //否则直接相加
}
```

**于是，相加代码就是这样了**

### 看似已完成，输出却全是坑

你以为这样就做完了？评测姬告诉你：**Too Young Too Simple**

**输出里还有一些坑，把你坑的头皮发麻。**

平常的输出方式是什么？我们现在知道了两个数的最大位，上面也有提到过。我们用 $maxl$ 表示。

**因为我们是从个位，逐渐递增存每位上的信息，但是我们要从最高位开始输出，也就是我们要先输出最高位。** 这倒是和字符串有点相似。

于是我们采用倒着输出方法，代码大概是这个样子。

```
for (int i = maxl; i > 0; i--) cout << ans[i];
```

但是！坑来了。

- 坑点 $1$

**如果你用 $10000+1$，会发生什么？**

当然你会知道它应该输出 $10001$。可你的计算机不这么认为。

依照上面的输出方法，此时 $maxl$ 为 $6$。**那么，它输出的就不是 $10001$，而是 $010001$ ！**，因为他会输出 $maxl$ 次，也就是 $5$ 次，并且是从 $ans_6$ 输到 $ans_1$。**但此时：$ans_6$ 已经为 $0$**

所以我们不得不考虑，在相加后位数 $<maxl$ 的情况下，不特殊处理就会多输出若干个 $0$。

解决方法很简单，输出前加上这么一句话即可：

```cpp
while(ans[maxl] == 0) maxl--;
//如果最高位为0，就一直减小最高位，直到不为0为止。
```

由于 $maxl$ 直接为输出的 `for` 循环服务，减小 $maxl$ 相当于减少了循环输出次数。最后，$ans_{maxl}$ 会停留在第一个不为 $0$ 的位置。

- 坑点 $2$

上面的坑点提到要去除多余的前导零，**但是，是不是所有的前导零都是多余的？**

**要是答案输出本身就为 $0$，前导零就是他本身。这个时候我们仍然要输出一个 $0$。** ，如果我们不处理这个地方，**上面处理前导零的代码就会把需要输出的 $0$ 也给处理掉。**

**也就是说，当两减数相等，答案为 $0$，不处理这个地方，代码什么都不会输出。**

所以我们要在最后输出时这么写：

```cpp
if(maxl < 1) cout << "0";
//最大位小于1，也就是最高位为0时输出。
//最高位为0，显而易见答案就为0了
//这种情况下前面什么都不会输出，这里额外输出一个0倒也无伤大雅
```

$\Huge 上代码!$

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

string a0, b0;
int a[maxn], b[maxn], ans[maxn];
int main() {
	cin >> a0 >> b0;
	for (int i = 1; i <= a0.size(); i++) a[i] = a0[a0.size() - i] - '0';
	for (int i = 1; i <= b0.size(); i++) b[i] = b0[b0.size() - i] - '0';
	int maxl = max(a0.size(), b0.size()) + 1;
	for (int i = 1; i <= maxl; i++) {
	    if(ans[i] + a[i] + b[i] >= 10) { //要进位
	    	ans[i + 1]++; //向前+1
            ans[i] += a[i] + b[i] - 10; //进位
	    } else ans[i] += a[i] + b[i]; //否则直接相加
    }
    while(ans[maxl] == 0) maxl--;
	for (int i = maxl; i > 0; i--) cout << ans[i];
	if(maxl < 1) cout << "0";
	return 0;
}
```

## [高精度减法](https://www.acwing.com/problem/content/794/)

```cpp
#include<bits/stdc++.h>
#define maxn 100010
using namespace std;

string a0, b0;
int a[maxn], b[maxn], ans[maxn];
bool bj(int al, int ar, int bl, int br) {
	int lena = ar - al + 1;
	int lenb = br - bl + 1;
	if(lena > lenb) return 1;
	else if(lenb > lena) return 0;
	for (int i = ar, j = br; i >= al; i--, j--)
		if(a[i] > b[j]) return 1;
		else if(a[i] < b[j]) return 0;
	return 1;
}

void jian1(int al, int ar, int bl, int br) {
	int maxl = max(ar - al + 1, br - bl + 1);
	for (int i = 1; i <= maxl; i++) {
		if(a[i] < b[i]) a[i + 1]--, a[i] += 10; 
		ans[i] = a[i] - b[i];
	}
	while(ans[maxl] == 0) maxl--;
	for (int i = maxl; i > 0; i--) cout << ans[i];
	if(maxl < 1) cout << "0";
}

void jian2(int al, int ar, int bl, int br) {
	int maxl = max(ar - al + 1, br - bl + 1);
	for (int i = 1; i <= maxl; i++) {
		if(b[i] < a[i]) b[i + 1]--, b[i] += 10; 
		ans[i] = b[i] - a[i];
	}
	while(ans[maxl] == 0) maxl--;
	for (int i = maxl; i > 0; i--) cout << ans[i];
	if(maxl < 1) cout << "0";
}

int main() {
	cin >> a0 >> b0;
	int l1 = a0.size(), l2 = b0.size();
	for (int i = 1; i <= a0.size(); i++) a[i] = a0[a0.size() - i] - '0';
	for (int i = 1; i <= b0.size(); i++) b[i] = b0[b0.size() - i] - '0';
	if(bj(0, a0.size(), 0, b0.size())) jian1(0, a0.size(), 0, b0.size()); //如果a0>=b0，则直接做减法
	else cout << "-", jian2(0, a0.size(), 0, b0.size()); //否则输出"-"，再让b0-a0
	return 0;
}
```

# 前缀和与差分

## [前缀和](https://www.acwing.com/problem/content/797/)

首先做一个预处理，定义一个 `sum` 数组，$sum_i$ 代表 $a$ 数组中前 $i$ 个数的和。

> $sum_r = a_1 + a_2 + a_3 + ... + a_{l-1} + a_l + a{l+1} + ...... +a_r$
> $sum_{l-1} = a_1 + a_2 + a_3 + ... + a_{l-1}$
> $sum_r - sum_{l-1} = a_l + a_{l+1} + ...... +a_r$

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_3d34e346d2-20201213222213524.png)

求前缀和运算：

```cpp
for (int i = 1; i <= n;i++) sum[i] = sum[i - 1] + a[i];
```

查询操作：

```cpp
cin >> l >> r;
cout << sum[r] - sum[l - 1] << endl;
```

对于每次查询，只需执行 `sum[r] - sum[l - 1]`，时间复杂度为 $O(1)$

总结：

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_492fcf08d2-20201217174953403.png)

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, q, s[maxn], a[maxn];
int main() { 
	cin >> n >> q;
	for (int i = 1; i <= n; i++) cin >> a[i];
	for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];
	while(q--) {
		int l, r;
		cin >> l >> r;
		cout << s[r] - s[l - 1] << endl;
	}
	return 0;
}
```

## [子矩阵的和](https://www.acwing.com/problem/content/798/)

如图：

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_c9a2bee0d2-20201217174700577.png)

紫色面积是指 $(1,1)$ 左上角到 $(i,j-1)$ 右下角的矩形面积, 绿色面积是指 $(1,1)$ 左上角到 $(i-1, j)$右下角的矩形面积。每一个颜色的矩形面积都代表了它所包围元素的和。

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_d9329a0dd2-20201216215336857.png)

从图中我们很容易看出，$整个外围蓝色矩形面积 s_{i\ j} = 绿色面积 s_{i-1\ j} + 紫色面积 s_{i\ j-1} - 重复加的红色的面积 s_{i-1\ j-1} + 小方块的面积 a_{i\ j}$;

因此得出二维前缀和预处理公式 `s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + a[i][j];`

接下来回归问题去求以 $(x1,y1)$ 为左上角和以 $(x2,y2)$ 为右下角的矩阵的元素的和。

如图：

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_e76d64f1d2-2020121717473287.png)

紫色面积是指 $( 1,1 )$ 左上角到 $(x1-1,y2)$ 右下角的矩形面积 ，黄色面积是指 $(1,1)$ 左上角到 $(x2,y1-1)$ 右下角的矩形面积；

不难推出：


$绿色矩形的面积 = 整个外围面积 s_{x2\ y2} - 黄色面积 s_{x2\ y1-1} - 紫色面积s[x1 - 1\ y2] + 重复减去的红色面积 s_{x1-1\ y1-1}$

因此二维前缀和的结论为：

以 $(x1, y1)$ 为左上角，$(x2, y2)$ 为右下角的子矩阵的和为：`s[x2][y2] - s[x2][y1 - 1] - s[x1 - 1][y2] + s[x1 - 1][y1 - 1]`

## [差分](https://www.acwing.com/problem/content/799/)

类似于数学中的求导和积分，差分可以看成前缀和的逆运算。

差分数组：

首先给定一个原数组`a：a[1], a[2], a[3],,,,,, a[n];`

然后我们构造一个数组`b： b[1] ,b[2] , b[3],,,,,, b[i];`

使得 `a[i] = b[1] + b[2 ]+ b[3] +,,,,,, + b[i]`

也就是说，$a$ 数组是 $b$ 数组的前缀和数组，反过来我们把 $b$ 数组叫做 $a$ 数组的差分数组。换句话说，每一个 $a_i$ 都是 $b$ 数组中从头开始的一段区间和。

考虑如何构造差分 $b$ 数组？

最为直接的方法，如下：

```cpp
b[1] = a[1] - a[0];
b[2] = a[2] - a[1];
b[3] = a[3] - a[2];
...
b[n] = a[n] - a[n - 1];
```

图示：

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_709830afd2-20201217174809672.png)

我们只要有 $b$ 数组，通过前缀和运算，就可以在 $O(n)$ 的时间内得到 $a$ 数组 。

知道了差分数组有什么用呢？ 别着急，慢慢往下看。

话说有这么一个问题：

给定区间 $[l ,r ]$，让我们把 $a$ 数组中的 $[ l, r]$ 区间中的每一个数都加上 $c$,即 $a_l + c , a_{l+1} + c , a_{l+2} + c ,,,,,, a_r + c$;

暴力做法是 `for` 循环 $l$ 到 $r$ 区间，时间复杂度 $O(n)$，如果我们需要对原数组执行 $m$ 次这样的操作，时间复杂度就会变成 $O(nm)$。有没有更高效的做法吗? 考虑差分做法。

始终要记得，$a$ 数组是 $b$ 数组的前缀和数组，比如对 $b$ 数组的 $b_i$ 的修改，会影响到 $a$ 数组中从 $a_i$ 及往后的每一个数。

首先让差分b数组中的 $b_l + c$, $a$ 数组变成 $a_l + c ,a_{l+1} + c,,,,,, a_n + c$;

然后我们打个补丁， $b_{r + 1} - c$, $a$ 数组变成 $a_{r +1} - c ,a_{r+2} - c,,,,,, a_n - c$;

为啥还要打个补丁？

我们画个图理解一下这个公式的由来:

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_7bd462bed2-20201215163431253.png)

$b_l+c$，效果使得 $a$ 数组中 $a_l$ 及以后的数都加上了 $c$ （红色部分），但我们只要求 $l$ 到 $r$ 区间加上 $c$, 因此还需要执行 $b_{r + 1} - c$,让 $a$ 数组中 $a_{r + 1}$ 及往后的区间再减去 $c$ （绿色部分），这样对于 $a_r$ 以后区间的数相当于没有发生改变。

总结：

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_863a40fed2-20201217172005485.png)

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, q, s[maxn], a[maxn];
void insert(int l, int r, int c) { //加入
	s[l] += c; //加上
	s[r + 1] -= c; //减去
}

int main() { 
	cin >> n >> q;
	for (int i = 1; i <= n; i++) cin >> a[i];
	for (int i = 1; i <= n; i++) s[i] = a[i] - a[i - 1]; //构造
	while(q--) {
		int l, r, c;
		cin >> l >> r >> c;
		insert(l, r, c);
	}
	for (int i = 1; i <= n; i++) s[i] += s[i - 1]; //把所有的s全跑一遍前缀和，重构a数组
	for (int i = 1; i <= n; i++) cout << s[i] << " ";
	return 0;
}
```

## [差分矩阵](https://www.acwing.com/problem/content/800/)

如果扩展到二维，我们需要让二维数组被选中的子矩阵中的每个元素的值加上 $c$，是否也可以达到 $O(1)$ 的时间复杂度。答案是可以的，考虑二维差分。

$a$ 数组是 $b$ 数组的前缀和数组，那么 $b$ 是 $a$ 的差分数组

原数组：$a_{i\ j}$

我们去构造差分数组：$b_{i\ j}$

使得 $a$ 数组中 $a_{i\ j}$ 是 $b$ 数组左上角 $(1,1)$ 到右下角 $(i,j)$ 所包围矩形元素的和。

如何构造 $b$ 数组呢？

我们去逆向思考。

同一维差分，我们构造二维差分数组目的是为了让原二维数组 $a$ 中所选中子矩阵中的每一个元素加上 $c$ 的操作，可以由 $O(n^2)$ 的时间复杂度优化成 $O(1)$

已知原数组 $a$ 中被选中的子矩阵为以 $(x1,y1)$ 为左上角，以 $(x2,y2)$ 为右下角所围成的矩形区域;

始终要记得，$a$ 数组是 $b$ 数组的前缀和数组，比如对 $b$ 数组的 $b_{i\ j}$ 的修改，会影响到 $a$ 数组中从 $a_{i\ j}$ 及往后的每一个数。

假定我们已经构造好了 $b$ 数组，类比一维差分，我们执行以下操作
来使被选中的子矩阵中的每个元素的值加上 $c$

```cpp
b[x1][y1] += c;
b[x2 + 1][y1] -= c;
b[x1][y2 + 1] -= c;
b[x2 + 1][y2 + 1] += c;
```

每次对 $b$ 数组执行以上操作，等价于：

```cpp
for (int i = x1; i <= x2; i++)
    for (int j = y1; j <= y2; j++)	
        a[i][j] += c;
```

我们画个图去理解一下这个过程：

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_0cbaf7e5d2-20201217174836198.png)

`b[x1][y1] += c;` 对应图 $1$，让整个 $a$ 数组中蓝色矩形面积的元素都加上了 $c$。
`b[x2 + 1][y1] -= c;` 对应图 $2$，让整个 $a$ 数组中绿色矩形面积的元素再减去 $c$，使其内元素不发生改变。

`b[x1][y2 + 1] -= c;` 对应图 $3$ ,让整个 $a$ 数组中紫色矩形面积的元素再减去 $c$，使其内元素不发生改变。
`b[x2 + 1][y2 + 1] += c;` 对应图 $4$,,让整个 $a$ 数组中红色矩形面积的元素再加上 $c$，红色内的相当于被减了两次，再加上一次 $c$，才能使其恢复。

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_1e2c1a36d2-20201217170336254.png)

我们将上述操作封装成一个插入函数：

```cpp
void insert(int x1, int y1, int x2, int y2, int c) {
	b[x1][y1] += c;
	b[x2 + 1][y1] -= c;
	b[x1][y2 + 1] -= c;
	b[x2 + 1][y2 + 1] += c;
}
```

我们可以先假想 $a$ 数组为空，那么 $b$ 数组一开始也为空，但是实际上 $a$ 数组并不为空，因此我们每次让 $b$ 数组以 $(i,j)$ 为左上角到以 $(i,j)$ 为右下角面积内元素（其实就是一个小方格的面积）去插入 $c=a_{i\ j}$，等价于原数组 $a$ 中 $(i,j)$ 到 $(i,j)$ 范围内加上了 $a_{i\ j}$ ,因此执行 $n\times m$ 次插入操作，就成功构建了差分 $b$ 数组。

总结：

![png](https://cdn.acwing.com/media/article/image/2023/04/04/29688_2f34208bd2-20201217172035975.png)

```cpp
#include <bits/stdc++.h>
#define maxn 1010
using namespace std;

int n, m, q, s[maxn][maxn], a[maxn][maxn];
void insert(int x1, int y1, int x2, int y2, int c) {
	s[x1][y1] += c;
	s[x2 + 1][y1] -= c;
	s[x1][y2 + 1] -= c;
	s[x2 + 1][y2 + 1] += c;
}

int main() { 
	cin >> n >> m >> q;
	for (int i = 1; i <= n; i++)
		for (int j = 1; j <= m; j++)
			cin >> a[i][j];
	for (int i = 1; i <= n; i++)
		for (int j = 1; j <= m; j++)
			insert(i, j, i, j, a[i][j]);
	while(q--) {
		int x1, x2, y1, y2, c;
		cin >> x1 >> y1 >> x2 >> y2 >> c;
		insert(x1, y1, x2, y2, c);
	}
	for (int i = 1; i <= n; i++)
		for (int j = 1; j <= m; j++)
			s[i][j] += s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1];
	for (int i = 1; i <= n; i++, puts(""))
		for (int j = 1; j <= m; j++)
			cout << s[i][j] << " ";
	return 0;
}
```

# 双指针算法

## [最长连续不重复子序列](https://www.acwing.com/problem/content/801/)

定义双指针 $l=1,r=1$，之后不停地移动 $r$；如果 $a_r$ 没有重复出现，则进行记录，并且 $r+1$；否则，则不停的 $l+1$，每次 $l+1$ 就对 $l$ 当前所在的数清空记录，直到 $a_r$ 不再记录里面，则更新；

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, l = 1, r = 1, ans, a[maxn];
bool vis[maxn];
int main() {
	cin >> n;
	for (int i = 1; i <= n; i++) cin >> a[i];
	while(r <= n) {
		if(vis[a[r]] == 0) vis[a[r++]] = 1; //进行记录
		else {
			while(vis[a[r]] == 1) vis[a[l++]] = 0; //直到没有出现过
			vis[a[r++]] = 1; //进行记录
		}
		ans = max(ans, r - l); //比较答案
	}
	cout << ans << endl;
	return 0;
}
```

## [数组元素的目标和](https://www.acwing.com/problem/content/description/802/)

发现有单调性，因此使用~~二分查找~~双指针。

定义两个指针 $l=1,r=m$

如果 $a_l+b_r>x$，说明 $r$ 太大了，则 $r-1$

如果 $a_l+b_r=x$，说明找到解了。

之后双指针的时候不停移动 $l$，直到 $l>n$

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, m, x, a[maxn], b[maxn];
int main() {
	cin >> n >> m >> x;
	for (int i = 1; i <= n; i++) cin >> a[i];
	for (int i = 1; i <= m; i++) cin >> b[i];
	int l = 1, r = m;
	while(l <= n && r >= 1) {
		while(a[l] + b[r] > x && r >= 1) r--;
		if(r >= 1 && a[l] + b[r] == x) cout << l - 1 << " " << r - 1 << endl;
		l++;
	}
	return 0;
}
```

## [判断子序列](https://www.acwing.com/problem/content/description/2818/)

1. $r$ 指针用来扫描整个 $b$ 数组，$l$ 指针用来扫描 $a$ 数组。若发现 $a[i] = b[j]$，则让 $l$ 指针后移一位。
2. 整个过程中，$r$ 指针不断后移，而 $l$ 指针只有当匹配成功时才后移一位，若最后若 $l > n$，则说明匹配成功。

**为什么双指针做法是正确的？**

整个过程中 $r$ 指针不断扫描 $b$ 数组并且向后移动，相当于不断给 $l$ 指针所指向的 $a$ 数组创建匹配的机会，只有匹配成功时 $l$ 指针才会向后移动一位，当 $l > n$ 时，说明全部匹配成功。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, m, a[maxn], b[maxn]; 
signed main() {
	cin >> n >> m;
	if(n > m) {
		cout << "No" << endl;
		return 0;
	}
	for (int i = 1; i <= n; i++) cin >> a[i];
	for (int i = 1; i <= m; i++) cin >> b[i];
	int l = 1, r = 1;
	while(l <= n && r <= m) {
		if(a[l] == b[r]) l++;
		r++;
	}
	if(l <= n) cout << "No" << endl;
	else cout << "Yes" << endl;
	return 0;
}
```

# 位运算

## [二进制中1的个数](https://www.acwing.com/problem/content/803/)

每得到一个数就减去他末尾的数，一直如此下去，时间复杂度 $O(n\log a_i)$

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, a[maxn];
signed main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) {
        int sum = 0;
        while(a[i]) {
            sum += a[i] % 2; //每次加上末尾的数
            a[i] /= 2; //去掉末尾的数
        }
        cout << sum << " ";
    }
	return 0;
}
```

# 离散化

## [区间和](https://www.acwing.com/problem/content/804/)

考虑数小一点的情况，即

> $1\le x \le 10 ^ 7$
>
> $0\le l\le r \le 10 ^ 7$

看到区间和，很明显就能想到使用前缀和解决！

$\Huge\color\red\text{但是!}$

数据太大了，前缀和解决不了，但我们可以发现一个问题。

> $1\le n,m \le10 ^ 5$

也就是说，这些点最多只有 $3\times 10^5$，其他点全都是没有用的。

我们可以尝试的只留下这些有用的点，而其它点就不需要了。

因此我们可以使用 `vector` 来把这些点存起来，之后要用的时候直接从 `vector` 里面找到对应的下标就好了。

```cpp
#include <bits/stdc++.h>
#define maxn 1000010 
using namespace std;

int n, m, qsum[maxn];
vector<int>alls;
struct node {
	int a, b;
};

int find(int x) { //从vector里面二分找到x的下标
	int l = 0, r = alls.size() - 1;
	while(l <= r) {
		int mid = (l + r) / 2;
		if(alls[mid] == x) return mid + 1; //+1的原因是因为从1~n的前缀和不需要考虑边界
		else if(alls[mid] < x) l = mid + 1;
		else r = mid - 1;
	}
}

vector<node>add, query;
signed main() {
	cin >> n >> m;
	for (int i = 1; i <= n; i++) {
		int x, c;
		cin >> x >> c;
		add.push_back({x, c}); //把每一个点存放的东西记录下来
		alls.push_back(x); //记录这个点
	}
	for (int i = 1; i <= m; i++) {
		int l, r;
		cin >> l >> r;
		query.push_back({l, r}); //同理，记录每一个待查询的区间
		alls.push_back(l); //记录这个点
		alls.push_back(r); //记录这个点
	}
	sort(alls.begin(), alls.end()); //排序
	alls.erase(unique(alls.begin(), alls.end()), alls.end()); //去重
	for (auto i:add) {
		int x = find(i.a); //找到对应的下标
		qsum[x] += i.b; //前缀和！启动！
	}
	for (int i = 1; i <= maxn; i++) qsum[i] += qsum[i - 1]; //完整前缀和
	for (auto i:query) {
		int l = find(i.a), r = find(i.b); //查找对应的下标
		cout << qsum[r] - qsum[l - 1] << endl; //前缀和
	} 
	return 0;
}
```

# 区间合并

## [区间合并](https://www.acwing.com/problem/content/805/)

先给左端点进行排序，之后贪心直接过，时间复杂度 $O(n\log n)$。

```cpp
#include <bits/stdc++.h>
#define int long long
#define maxn 100010
using namespace std;

int n, ans;
struct node {
	int l, r;
}a[maxn];

bool cmp(node x, node y) {
	return x.l < y.l;
}

signed main() {
	cin >> n;
	for (int i = 1; i <= n; i++) cin >> a[i].l >> a[i].r;
	sort(a + 1, a + n + 1, cmp);
	int l = -2e9, r = -2e9;
	for (int i = 1; i <= n; i++) {
		if(r < a[i].l) {
			ans++;
			l = a[i].l, r = a[i].r;
		} else r = max(r, a[i].r);
	}
	cout << ans << endl;
	return 0;
}
```
