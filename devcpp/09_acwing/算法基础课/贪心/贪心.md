# 区间问题

## [区间选点](https://www.acwing.com/problem/content/description/907/)

贪心做法：

1. 将每个区间按照右端点从小到大进行排序

2. 从前往后枚举区间，选取第一个区间的右端点 $x$ 当指针，若 $a_i$ 左端点 $>x$，说明这个点不能被 $a_i$ 包含了，则 $x=a_i$ 的右端点，接着枚举区间。

贪心证明：

设最优解是 $ans$，算法解是 $cnt$，则：

1. 证明 $ans\le cnt$：$cnt$ 是一种可行方案， $ans$ 是可行方案的最优解，也就是最小值。

2. 证明 $ans\ge cnt$：$cnt$ 可行方案是一个区间集合，区间从小到大排序，两两之间不相交。

所以覆盖每一个区间至少需要 $cnt$ 个点。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, ans = 1; //至少要选出一个点
struct node {
    int a, b;
} a[maxn];

bool cmp(node x, node y) {
    return x.b < y.b; //按右端点排序
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].a >> a[i].b;
    sort(a, a + n, cmp);
    int x = a[0].b; //选取第一个区间的右端点
    for (int i = 1; i < n; i++)
        if(x < a[i].a) x = a[i].b, ans++; //开辟新点
    cout << ans << endl;
    return 0;
}
```

## [最大不相交区间数量](https://www.acwing.com/problem/content/910/)

贪心做法：

1. 将区间按右端点排序

2. 遍历区间，如果该区间和上一个选的区间有重合，则跳过。如果和上一个选的区间没有重合，则选取该区间。

贪心证明：

假设最优解为 $ans$ 个区间，贪心算法求出的为 $cnt$ 个区间。 只需要证明 $ans = cnt$ 即可。

该贪心算法求出的结果一定是符合区间两两不相交要求的，因此 $ans \ge cnt$。

没有被选中的区间，一定是被某个选中区间 pass 掉的，把选中的某个区间和被该区间 pass 掉的所有区间看做一个集合，则共有 $cnt$ 个集合。

每个集合中的区间，被 pass 掉的区间的右端点一定大于该集合中选中区间的右端点，因为是按照右端点排序后遍历的，所有选中区间只能 pass 掉右端点比他大的区间。

每个集合中的区间，被 pass 掉的区间的左端点一定小于该集合中选中区间的右端点，因为如果某个区间的左端点大于选中区间的右端点，则这个区间一定不会被 pass 掉。（pass 掉的条件是该区间左端点小于选中区间的右端点）

综合上面两个条件：每个集合中的区间一定两两相交。

假设 $ans > cnt$，根据抽屉原理，一定有某个集合中被选中了 $1$ 个以上的区间。又因为同一集合中的区间两两相交，因此，如果 $ans > cnt$，则必定有区间是相交的，与题意矛盾，因此 $ans$ 不能大于 $cnt$。

综上：$ans \ge cnt$ 且 $ans\le cnt$，所以 $ans = cnt$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, ans = 1; //因为第一个区间肯定会被选走，所以 ans 初始化为1
struct node {
    int a, b;
} a[maxn];

bool cmp(node x, node y) {
    return x.b < y.b; //按右端点排序
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].a >> a[i].b;
    sort(a, a + n, cmp);
    int x = a[0].b; //每次记录上一个选中区间的右端点
    for (int i = 1; i < n; i++)
        if(x < a[i].a) x = a[i].b, ans++; //不相交，则更新x，ans+1
    cout << ans << endl;
    return 0;
}
```

## [区间分组](https://www.acwing.com/problem/content/908/)

贪心做法：

1. 将区间按左端点排序。

2. 依次遍历区间，如果当前区间能放到之前的某个集合中，则把该区间放到该集合，如果当前不能放到任意一个之前的集合中，则新开一个集合，把当前区间放到新开的集合中。

3. 集合的数量就是答案。

**关键步骤是第二步**，如何判断当前区间能否放到之前的集合中。解决方法如下:

1. 记录每个集合中保存的区间的最右侧端点，如果当前区间的左端点不和某个集合中保存的区间的最右侧端点相交，则当前区间不和该集合相交，能放到该集合中。

2. 也就是，我们只需判断当前区间的左端点与**右侧端点最小的那个集合**是否相交即可。

为了快速找出右侧端点最小的那个集合，可以使用小根堆保存每个集合的右端点。

贪心证明：

设最优解为 $ \text{ans} $，算法解为 $ \text{cnt} $

1. 我们的方法找到的集合，各个集合中的区间，两两肯定不相交，因此 $ \text{cnt} \geq \text{ans} $

2. 按照该算法，各个集合中的最后一个区间一定是两两相交的。如果存在不相交的区间，则这两个区间会被放到同一个集合中。

3. 集合的数量，一定是当遍历到某个区间的时候，不能把当前区间放到任意一个集合中，导致了集合数量由 $ \text{cnt} - 1 $ 变为 $ \text{cnt} $。也就是当前区间一定各个集合的最后一个区间有重叠部分。

4. 综合2、3，各个集合的最后一个区间两两相交，当前遍历到的区间和各个集合的最后一个区间都相交，因此，当前遍历的区间以及各个集合的最后一个区间两两相交。对于集合数量由 $ \text{cnt} - 1 $ 变为 $ \text{cnt} $ 的时候，一定有 $ \text{cnt} $ 个区间两两相交。

5. 为了将这 $ \text{cnt} $ 个区间互不相交，至少需要 $ \text{cnt} $ 个集合，因此 $ \text{cnt} \leq \text{ans} $

6. 由 1 得出 $ \text{cnt} \geq \text{ans} $，由 5 得出 $ \text{cnt} \leq \text{ans} $，所以 $ \text{cnt} = \text{ans} $。

**为什么不能右端点排序？**

![](https://cdn.acwing.com/media/article/image/2022/04/04/140845_5db5b6fdb3-%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE-2022-04-04-174103.png)

上图的这个九个区间最少能分三个组，每组就是图中的一行。

但是按右端点排序法，分组情况就如下图所示，会导致多分出一个组。因为第三个黄色区间右端点小于第三个绿色区间，所以第三个黄色抢了第三个绿色的位置。

![](https://cdn.acwing.com/media/article/image/2022/04/04/140845_eade19eab3-%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE-2022-04-04-174507.png)

由此可见，右端点排序法能使剩余空间更大，但并不能保证区间更紧凑。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, ans = 1;
struct node {
    int l, r;
    bool operator<(const node &w) {
        return l < w.l; //按左端点排序
    }
} a[maxn];

priority_queue<int, vector<int>, greater<int> > heap; //小顶堆
int main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].l >> a[i].r;
    sort(a, a + n);
    for (int i = 0; i < n; i++) {
        node x = a[i];
        if (heap.empty() || heap.top() >= x.l) heap.push(x.r); //如果堆是空的，或者所有集合中最小的右侧端点都比>=当前区间左端点，说明一定会产生相交，则放入一个新的集合
        else heap.pop(), heap.push(x.r); //否则更新那个集合的右侧端点
    }
    cout << heap.size() << endl; //堆的大小就是答案
    return 0;
}
```

## [区间覆盖](https://www.acwing.com/problem/content/909/)

贪心做法：

1. 将所有区间按照左端点从小到大进行排序。
2. 从前往后枚举每个区间，在所有能覆盖 `start` 的区间中，选择右端点的最大区间，然后将 `start` 更新成右端点的最大值。

贪心证明：

感性理解为，每次选举能覆盖 `start` 的区间，且挑出它们中右端点最大的区间，可以使得答案最优（说白了就是题解区没有人给出证明，因此不会写证明）。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

const int inf = 2e9;
int n, s, t, ans;
bool is = false; //判断是否有答案
struct node {
    int l, r;
} a[maxn];

bool cmp(node x, node y) {
    return x.l < y.l;
}

int main() {
    cin >> s >> t >> n;
    for (int i = 0; i < n; i++) cin >> a[i].l >> a[i].r;
    sort(a, a + n, cmp);
    for (int i = 0; i < n; i++) {
        int j = i, cnt = -inf;
        while (j < n && a[j].l <= s) cnt = max(cnt, a[j].r), j++; //不停地枚举覆盖 start 的区间
        if (cnt < s) break; //如果最大的右端点都不能覆盖到s，说明无解
        ans++; //需要选出的区间+1
        if (cnt >= t) { //如果找到的区间超过了t，说明找到了答案
            is = 1;
            break;
        }
        i = j - 1, s = cnt; //由于上面的while循环中，j会在末尾+1，也就是多算了一个区间，我们也要把这个区间算上
    }
    if (!is) cout << -1 << endl;
    else cout << ans << endl;
    return 0;
}
```

# Huffman树

## [合并果子](https://www.acwing.com/problem/content/150/)

我们可以用贪心的方法，让每次合并的两堆果子的数量都尽可能小，取当前 $h$ 中的两个最小值，合并。

则每次合并消耗的体力最少，总消耗体力就最少，记录体力的同时，还要将产生的新果子堆重新插入。

既然有了取最小值与插入新堆两个操作，我们就想到了用小根堆。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, m, ans, a[maxn];
struct node {
    int val;
    bool operator<(const node &t) const { return val < t.val; }
};

//
// bool operator<(int x, int y) {
//	return x < y;
//}

priority_queue<int, vector<int>, greater<int> > q;

void push(int x) {
    a[++n] = x;
    int t = n;
    while (t != 1 && a[t] <= a[t / 2]) {
        swap(a[t], a[t / 2]);
        t /= 2;
    }
}

void pop() {
    swap(a[n--], a[1]);
    int t = 1;
    while (t <= n) {
        if (t * 2 + 1 <= n && a[t * 2] <= a[t * 2 + 1])
            t = t * 2;
        else if (t * 2 + 1 <= n && a[t * 2 + 1] <= a[t * 2])
            t = t * 2 + 1;
        else if (t * 2 <= n && t * 2 + 1 >= n)
            t = t * 2;
        else
            break;
        if (t > n)
            break;
        else
            swap(a[t / 2], a[t]);
    }
}

int main() {
    cin >> m;
    for (int i = 1; i <= m; i++) {
        int t;
        cin >> t;
        q.push(t); //放入堆中
    }
    while (q.size() > 1) {
        int t1 = q.top(); q.pop(); //取出最小值和次小值
        int t2 = q.top(); q.pop();
        ans += t1 + t2; //计算答案
        q.push(t1 + t2); //插入新堆
    }
    cout << ans << endl;
    return 0;
}
```

# 排序不等式

## [排队打水](https://www.acwing.com/problem/content/description/915/)

众所周知，第 $i$ 个人打水别人需要等待的时间为 $a_i\times (n-i)$。

贪心做法：

1. 将 $a$ 从小到大排序。
2. 从后往前累加 $a_i\times (n-i)$。

贪心证明：

设 $a_i>a_{i+1}$，由于变换后不会影响其他人打水带来的等待时间，因此下表列举出交换前与交换后需要等待的时间的变换。

|| $a_i$ 带来的贡献 | $a_{i+1}$ 带来的贡献 | 合计 |
| :--------: | :------: | :-------------: | :--: |
| **交换前** | $a_i\times(n-i)$ | $a_{i+1}\times(n-i-1)$ | $(a_i+a_{i+1})\times(n-i)-a_{i+1}$ |
| **交换后** | $a_i\times(n-i-1)$ | $a_{i+1}\times(n-i)$ | $(a_i+a_{i+1})\times(n-i)-a_i$ |

由于 $a_i>a_{i+1}$，因此交换后的贡献将会小一些。因此顺序 $\ge$ 乱序。

```cpp
#include <bits/stdc++.h>
#define int long long
#define maxn 100010
using namespace std;

int n, ans, a[maxn];
signed main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    sort(a + 1, a + n + 1);
    for (int i = 1; i <= n; i++) ans += a[i] * (n - i);
    cout << ans << endl;
    return 0;
}
```

# 绝对值不等式

## [货仓选址](https://www.acwing.com/problem/content/106/)

设 $x$ 为中心点，则总距离和为

$|a_1-x|+|a_2-x|+|a_3-x|+...+|a_n-x|=(|a_1-x|+|a_n-x|)+(|a_2-x|+|a_{n-1}-x|)+...=(a_n-a_1)+(a_{n-1}-a_2)+...$

算法步骤：

1. 给 $a$ 从小到大排序
2. 从 $n$ 的奇偶性分两种情况讨论：
   - 如果 $n$ 为奇数，则选择 $a_{\frac{n+1}{2}}$ 就行了。
   - 如果 $n$ 为偶数，则选择 $a_\frac{n}{2}\sim a_{\frac{n}{2}+1}$ 中随便一个数就行。

核心思路就是选择 $(a_1\sim a_n),(a_2\sim a_{n-1})...$ 之间的数。

```cpp
#include <bits/stdc++.h>
#define int long long
#define maxn 100010
using namespace std;

int n, ans, a[maxn];
signed main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    sort(a + 1, a + n + 1);
    for (int i = 1; i <= n / 2; i++) ans += a[n - i + 1] - a[i];
    cout << ans << endl;
    return 0;
}
```

# 推公式

## [耍杂技的牛](https://www.acwing.com/problem/content/127/)

贪心做法：

1. 给这些牛按 $w_i+s_i$ 从小到大排序
2. 从前往后依次相加即可。

贪心证明：

若存在相邻 $ i $ 和 $ i+1 $ 有 $ w_i + s_i > w_{i+1} + s_{i+1} $

- 可以发现此时交换第 $ i $ 头牛和第 $ i+1 $ 头牛不影响 $[0, i-1]$ 和 $[i+2, n]$ 的风险

| 变化 | 第 $ i $ 个位置上的牛 | 第 $ i+1 $ 个位置上的牛 |
|------|--------------------------|----------------------------|
| 交换前 | $ w_1 + \ldots + w(i-1) - s_i $ | $ w_1 + \ldots + w(i) - s(i+1) $ |
| 交换后 | $ w_1 + \ldots + w(i-1) - s(i+1) $ | $ w_1 + \ldots + w(i-1) + w(i+1) - s(i) $ |

- 前 $ i-1 $ 项减去

| 变化 | 第 $ i $ 个位置上的牛 | 第 $ i+1 $ 个位置上的牛 |
|------|--------------------------|----------------------------|
| 交换前 | $ -s_i $ | $ w(i) - s(i+1) $ |
| 交换后 | $ -s(i+1) $ | $ w(i+1) - s(i) $ |

- 加上 $ s_i + s_{i+1} $

| 变化 | 第 $ i $ 个位置上的牛 | 第 $ i+1 $ 个位置上的牛 |
|------|--------------------------|----------------------------|
| 交换前 | $ s(i+1) $ | $ w_i + s_i $ |
| 交换后 | $ s_i $ | $ w(i+1) + s(i+1) $ |

因为交换前的 $s_{i+1}+w_i+s_i\ge$ 交换后的 $s_{i+1}+w_{i+1}+s_i$

$$
w_i + s_i > s_i
$$

$$
w_i + s_i \geq w(i + 1) + s(i + 1)
$$

$$
w_i + s_i \geq \max(s_i, w(i + 1) + s(i + 1))
$$

由 $ w_i + s_i > w_{i+1} + s_{i+1} $

$$
w_i + s_i > s_{i+1}
$$

$$
w_i + s_i > w_{i+1} + s_{i+1}
$$

$$
w_i + s_i = \max(s_{i+1}, w_i + s_i)
$$

$$
\max(s(i + 1), w_i + s_i) \geq \max(s_i, w(i + 1) + s(i + 1))
$$

$$
\max(\text{交换前}) \geq \max(\text{交换后})
$$

因此，我们可以得到排序后得到的解是最优的。

```cpp
#include <bits/stdc++.h>
#define maxn 50010
#define int long long
using namespace std;

int n, qsum, ans = -1e15;
struct node {
    int w, s;
    bool operator<(const node &h) {
        return w + s < h.w + h.s; //排序
    }
} a[maxn];

signed main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].w >> a[i].s;
    sort(a, a + n);
    for (int i = 0; i < n; i++) {
        ans = max(ans, qsum - a[i].s);
        qsum += a[i].w;
    }
    cout << ans << endl;
    return 0;
}
```
