# 链表

## [单链表](https://www.acwing.com/problem/content/828/)

$head$ 表示头结点，$e$ 数组存储元素，$ne$ 数组存储下一个节点索引，$cnt$ 表示下一个可以存储元素的位置索引。

1. 头结点后面添加元素：

在 $e$ 的 $cnt+1$ 处存储元素 $e_{++cnt} = x$;

该元素插入到头结点后面 $ne_{cnt} = head$;

头结点指向该元素 $head = cnt$。

2. 在索引 $k$ 后插入一个数

在 $e$ 的 $cnt+1$ 处存储元素 $e_{++cnt} = x$；

该元素插入到第 $k$ 个插入的数后面 $ne_{cnt} = ne_k$;

第 $k$ 个插入的数指向该元素 $ne_k = cnt$。

3. 删索引为 $k$ 的元素的后一个元素：

$ne_k $ 的值更新为 $ne_{ne_k}$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int m, head, cnt, e[maxn], ne[maxn];
void init() {
	head = -1, cnt = 0;
}

void add_to_head(int x) {
	ne[++cnt] = head; //新节点的下一个节点是头节点 
	e[cnt] = x; //新节点的值 
	head = cnt; //更换头节点 
}

void add(int k, int x) {
	ne[++cnt] = ne[k]; //新节点的下一个节点是k的下一个节点 
	ne[k] = cnt; //更新k的下一个节点 
	e[cnt] = x; //更新节点的值 
}

void erase(int k) {
	if(k == 0) head = ne[head]; //删除头节点 
	else ne[k] = ne[ne[k]]; //更新下一个点 
}

signed main() {
	cin >> m, init();
	while(m--) {
		char op;
		int k, x;
		cin >> op;
		if(op == 'H') cin >> x, add_to_head(x);
		else if(op == 'D') cin >> k, erase(k);
		else cin >> k >> x, add(k, x);
	}
	for (int i = head; i != -1; i = ne[i]) cout << e[i] << " ";
	return 0;
}
```

## [双链表](https://www.acwing.com/problem/content/829/)

与单链表差不多，只是把 $ne$ 数组换成了 $l$ 数组和 $r$ 数组，表示左边的数和右边的数，而左右边界为 $0$ 和 $1$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int m, cnt, e[maxn], l[maxn], r[maxn];
void init() {
	r[0] = 1, l[1] = 0, cnt = 2;
}

void add_right(int k, int x) { //第k个点的右边插入点x
	e[++cnt] = x; //新节点的值 
	r[cnt] = r[k];
	l[cnt] = k;
	l[r[k]] = cnt; 
	r[k] = cnt;
}

void add_left(int k, int x) { //第k个点的左边插入点x
	e[++cnt] = x; //新节点的值 
	l[cnt] = l[k];
	r[cnt] = k;
	r[l[k]] = cnt; 
	l[k] = cnt;
}

void erase(int k) {
	r[l[k]] = r[k];
	l[r[k]] = l[k];
}

signed main() {
	cin >> m, init();
	while(m--) {
		string op;
		int k, x;
		cin >> op;
		if(op == "L") cin >> x, add_right(0, x);
		else if(op == "R") cin >> x, add_left(1, x);
		else if(op == "D") cin >> k, erase(k + 2); //由于0和1已经定义过了，所以要加上一个偏移量，下面同理 
		else if(op == "IL") cin >> k >> x, add_left(k + 2, x);
		else cin >> k >> x, add_right(k + 2, x);
	}
	for (int i = r[0]; i != 1; i = r[i]) cout << e[i] << " ";
	return 0;
}
```

# 栈

## [模拟栈](https://www.acwing.com/problem/content/830/)

栈是一种数据结构，用数组模拟栈的操作：

用 $top$ 表示栈顶所在的索引。初始时，$top = 0$。表示没有元素。

1. `push x` ：栈顶所在索引往后移动一格，然后放入 $x$。`st[++top] = x`。

2. `pop` : $top$ 往前移动一格。`top–-`。

3. `empty` ：$top$ 大于 $0$ 栈非空，小于等于 $0$ 栈空。`top == 0 ? “YES” : “NO”。`

4. `query` ： 返回栈顶元素。`st[top]`。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int m, top, stac[maxn];
void init() {
	top = 0;
}

void push(int x) {
	stac[++top] = x;
}

void pop() {
	top--;
}

bool empty() {
	return top == 0;
}

int query() {
	return stac[top];
}

signed main() {
	cin >> m, init();
	while(m--) {
		int x;
		string op;
		cin >> op;
		if(op == "push") cin >> x, push(x);
		else if(op == "pop") pop();
		else if(op == "empty") cout << (empty() ? "YES" : "NO") << endl;
		else cout << query() << endl;
	}
	return 0;
}
```

## [单调栈](https://www.acwing.com/problem/content/832/)

单调栈就是使栈内元素单调递增或者单调递减的栈，单调栈也只能在栈顶操作。

我们先来模拟一遍吧！

做一个比喻，比方说：有个集训队招人，一个数代表了一个选手的能力值，先进来的选手年龄会比较大，后面的选手年龄比较小，但是这个集训队没有人数限制，那么如果遇到一个比你小还比你强的人那么准备退役吧。

比如有 $5$ 个能力值分别是：

```cpp
1 4 2 3 1
```

要加进来这个单调栈。

首先是 $1$ 也就是选手 $1$ ，那么集训队没有人和他比较所以进入集训队。

单调栈的情况：$1$ 。

然后是 $4$ 也就是选手 $2$ ，那么我们可以发现，选手 $2$ 比选手 $1$ 要小，并且选手 $2$ 的能力比选手 $1$ 要强，那么选手 $1$ 留着也没啥用，淘汰！~~好残酷呀！~~

单调栈的情况：$4$ 。

然后是 $2$ 选手 $3$ ，选手 $3$ 比选手 $2$ 年龄要小，但是选手 $3$ 的能力没有选手 $2$ 强，那么选手 $3$ 招进集训队。

单调栈的情况：$4\ 2$ 。

那么接下来是 $3$ 选手 $4$ ，选手 $4$ 比选手 $3$ 年龄要小，比他还要强，选手 $3$ 淘汰！往后比较，发现 选手 $2$ 虽然比选手 $4$ 要大，但是他能力很强！所以不会被淘汰，将选手 $4$ 招进集训队。

单调栈的情况：$4\ 3$。

最后是 $1$ 选手 $5$ ，选手 $5$ 比选手 $4$ 要小，但是选手 $4$ 的能力比选手 $5$ 要强，所以选手 $5$ 必定也比不过选手 $2$ ，但由于选手 $5$ 小所以不淘汰他。

单调栈的情况：$4\ 3\ 1$ 。

通过这个模拟我们发现，~~如果你很强，就算你年龄大也不会被淘汰~~，其实不是这样，在单调队列（比单调栈高级的东西）里面你就算再强也终究有时候会退役的，所以好好珍惜吧！

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, top, a[maxn], st[maxn];
bool empty() {
	return top == 0;
}

void pop() {
	top--;
}

void push(int x) {
	int res = -1;
	while(!empty() && st[top] >= x) pop(); //集训队淘汰人（这次是<，因此要改一改） 
	cout << (empty() ? -1 : st[top]) << " "; //如果人没有了，就输出-1 
	st[++top] = x; //否则把人加进来 
}

signed main() {
	cin >> n;
	for (int i = 1; i <= n; i++) cin >> a[i];
	for (int i = 1; i <= n; i++) push(a[i]); 
	return 0;
}
```

# 队列

## [模拟队列](https://www.acwing.com/problem/content/831/)

队列是一种数据结构，用数组模拟队列的操作：

用 $l$ 表示队列所在的队头，$r$ 表示队列所在的队尾。初始时，$l=1,r=0$。表示没有元素。

1. `push x` ：队尾所在索引往后移动一格，然后放入 $x$。`que[++r] = x`。

2. `pop` : l$ 往后移动一格。`l++`。

3. `empty` ：$l\le r$ 队列非空，否则队列空。`l > r ? “YES” : “NO”。`

4. `query` ：返回队头元素。`que[l]`。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int m, l, r, que[maxn];
void init() {
	l = 1, r = 0;
}

void push(int x) {
	que[++r] = x;
}

void pop() {
	l++;
}

bool empty() {
	return l > r;
}

int query() {
	return que[l];
}

signed main() {
	cin >> m, init();
	while(m--) {
		int x;
		string op;
		cin >> op;
		if(op == "push") cin >> x, push(x);
		else if(op == "pop") pop();
		else if(op == "empty") cout << (empty() ? "YES" : "NO") << endl;
		else cout << query() << endl;
	}
	return 0;
}
```

## [滑动窗口](https://www.acwing.com/problem/content/156/)

以求滑动窗口的最大值为例。

- 如果当前的滑动窗口中有两个下标 $i$ 和 $j$ ，其中 $i$ 在 $j$ 的左侧 $(i<j)$，并且 $i$ 对应的元素不大于 $j$ 对应的元素 $(num_i < num_j)$，则：

当滑动窗口向右移动时，只要 $i$ 还在窗口中，那么 $j$ 一定也还在窗口中。这是由于 $i$ 在 $j$ 的左侧所保证的。

因此，由于 $nums_j$ 的存在，$num_i$ 一定不会是滑动窗口中的最大值了，我们可以将 $nums_i$ 永久地移除。

- 因此我们可以使用一个队列存储所有还没有被移除的下标。在队列中，这些下标按照从小到大的顺序被存储，并且它们在数组 $nums$ 中对应的值是严格单调递减的。

- 当滑动窗口向右移动时，我们需要把一个新的元素放入队列中。

为了保持队列的性质，我们会不断地将新的元素与队尾的元素相比较，如果新元素大于等于队尾元素，那么队尾的元素就可以被永久地移除，我们将其弹出队列。我们需要不断地进行此项操作，直到队列为空或者新的元素小于队尾的元素。

- 由于队列中下标对应的元素是严格单调递减的，因此此时队首下标对应的元素就是滑动窗口中的最大值。

- 窗口向右移动的时候。因此我们还需要不断从队首弹出元素保证队列中的所有元素都是窗口中的，因此当队头元素在窗口的左边的时候，弹出队头。

```cpp
#include <bits/stdc++.h>
#define maxn 1000010
using namespace std;

int n, k, l = 1, r = 0, a[maxn], maxv[maxn], minv[maxn], ansmax[maxn], ansmin[maxn];
void push_max(int x) {
    while(l <= r && a[maxv[r]] < a[x]) r--;
    maxv[++r] = x;
}

void push_min(int x) {
    while(l <= r && a[minv[r]] > a[x]) r--;
    minv[++r] = x;
}

signed main() {
    cin >> n >> k;
    for (int i = 1; i <= n; i++) cin >> a[i];
    memset(maxv, -1, sizeof(maxv));
    memset(minv, -1, sizeof(minv));
    for (int i = 1; i <= n; i++) {
        if (maxv[l] == i - k) l++;
        push_max(i);
        if (i >= k) ansmax[i] = a[maxv[l]];
    }
    l = 1, r = 0;
    for (int i = 1; i <= n; i++) {
        if (minv[l] == i - k) l++;
        push_min(i);
        if (i >= k) ansmin[i] = a[minv[l]];
    }
    for (int i = k; i <= n; i++) cout << ansmin[i] << " ";
    cout << endl;
    for (int i = k; i <= n; i++) cout << ansmax[i] << " ";
    cout << endl;
	return 0;
}
```

# KMP

## [KMP字符串](https://www.acwing.com/problem/content/833/)

基础知识：

1、$s$ 是文本串，即比较长的字符串。
2、$p$ 是模式串，即比较短的字符串。

$\texttt{KMP}$ 的基本思路：

普通算法由于每次失配只能向后移动一位，最坏情况下时间复杂度很高；而 $\texttt{KMP}$ 则考虑多移动几位，减少计算量。

---

- $next$ 数组的含义及使用：

$next$ 数组的含义：对 $next_i$，表示 $p[1,j]$ 串中前缀和后缀相同的最大长度。举个例子。

![](https://cdn.acwing.com/media/article/image/2020/06/12/31041_6f934f82ac-next%E4%BE%8B%E5%AD%90.PNG)

$next$ 数组的求法：

> 设两个指针 $i$ 与 $j$。$i$ 不停地从 $2$ 向右一直移动到末尾，$j=1$ 开始，之后用来匹配。
>
> 如果 $p_i=p_{j+1}$，则说明匹配成功，$next_i=j$，$j$ 向前挪动一步。
>
> 如果 $p_i\ne p_{j+1}$，则说明匹配失败，给 $j$ 指针一次反悔的机会，让 $j = next_j$，直到 $p_i=p_{j+1}$ 或 $j=0$（由于 $p[1\sim next_j] = p[j-next_j+1\sim j]$，所以在这种情况下进行反悔匹配是最优的）。
>
> 具体见下图：
>

>
> ----
>
> ![](http://dyoi.net:2024/file/873/%E6%97%A0%E6%A0%87%E9%A2%98.png)

---

- $\texttt{KMP}$ 匹配的过程：$s$ 串和 $p$ 串都是从 $1$ 开始的。$i$ 从 $1$ 开始，$j$ 从 $0$ 开始，每次 $s_i$ 和 $p_{j+1}$ 比较。

> 如果 $s_i=p_{j+1}$，则说明匹配成功，$j$ 向前挪动一步。
>
> 如果 $s_i\ne p_{j+1}$，则说明匹配失败，给 $j$ 指针一次反悔的机会，让 $j = next_j$，直到 $s_i=p_{j+1}$ 或 $j=0$（由于 $p[1\sim next_j] = p[j-next_j+1\sim j]$，所以在这种情况下进行反悔匹配是最优的）。
>
> 如果在上述两种操作都结束之后，$j=n(n=p\text{ 的长度})$，则说明找到符合子串，输出 $i-j$。
>
> ![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%873.png)

> ![](http://dyoi.net:2024/file/873/%E6%97%A0%E6%A0%87%E9%A2%98.png)

- 最终的代码：

```cpp
#include <bits/stdc++.h>
#define N 1000010
#define M 1000010
using namespace std;

int n, m, ne[N];
char S[M], P[N];
signed main() {
    cin >> n >> (P + 1) >> m >> (S + 1);
    for (int i = 2, j = 0; i <= n; i++) { //i从2开始 
        while(j && P[i] != P[j + 1]) j = ne[j]; //不停地给机会 
        if(P[i] == P[j + 1]) j++; //如果达到机会了，就+1 
        ne[i] = j; //记录 
    }
    for (int i = 1, j = 0; i <= m; i++) {
        while(j && S[i] != P[j + 1]) j = ne[j]; //不停地给机会 
        if(S[i] == P[j + 1]) j++; //达到机会了，指针挪一步 
        if(j == n) cout << i - n << " "; //输出 
    }
	return 0;
}
```

# Trie树

## [Trie字符串统计](https://www.acwing.com/problem/content/837/)

Trie树又称字典树、单词查找树。是一种能够高效存储和查找字符串集合的数据结构。咋看之下不是很复杂，但是仔细看代码又有点模糊。储存形式如下：

![](https://cdn.acwing.com/media/article/image/2020/06/13/31041_aa11ff2cad-Trie1.PNG)

1. **定义**

定义一个二维数组 $son$，$son[i][j]$ 表示第 $i$ 个节点，是否存在字母 $j$ （由于全是小写字母，因此都减去'a'）。

定义一个一维数组 $cnt$，$cnt[i]$ 表示以第 $i$ 个节点为结尾的单词的数量。

![](https://cdn.acwing.com/media/article/image/2020/06/13/31041_aed49a42ad-Trie2.PNG)

插入操作代码：

```cpp
void insert(string C) {
	int p = 0;
	for (int i = 0; C[i]; i++) {
		int u = C[i] - 'a';
		if(!son[p][u]) son[p][u] = ++idx; //如果没有这个点，则创建这个点
		p = son[p][u]; //之后接着走
	}
	cnt[p]++; //打标记
}
```

查询操作代码：

```cpp
int query(string C) {
	int p = 0;
	for (int i = 0; C[i]; i++) {
		int u = C[i] - 'a';
		if(!son[p][u]) return 0; //没有这个单词
		p = son[p][u]; //否则接着走
	}
	return cnt[p]; //最后的答案
}
```

## [最大异或对](https://www.acwing.com/problem/content/145/)

如果不是放在字典树单元的话，这道题目很难想到是字典树。

思路：一个整数，可以转化成为一个 $31$ 位的二进制数，而也就可以变成长度为 $31$ 位的二进制字符串.

既然如此话，那么我们可以这么做，每一次检索的时候，我们都走与当前 $a_i$ 这一位相反的位置走，也就是让 $xor$ 值最大，如果说没有路可以走的话，那么就走相同的路。

因为这样就可以遍历所有的情况呀，对于每一个数字选择的都是前面和它异或产生的值最大的数字，即使当前数字是和后面的某个数字异或值最大，遍历后面那个数字的时候就会将这个数字选择出来。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, son[maxn * 31][2], a[maxn], ans, idx;
/*
son[i][j]表示第i个节点有没有j这个字母这个儿子（因为最多有n个数，每个数转成二进制最多有31位，所以第一位要考到31*maxn） 
idx表示所有节点的下标，0即表示根节点，也表示空节点
*/
void insert(int C) {
	int p = 0;
	for (int i = 30; i >= 0; i--) {
		int u = (C >> i) % 2;
		if(!son[p][u]) son[p][u] = ++idx;
		p = son[p][u];
	}
	//长度都一样就不用cnt数组标记最后一位了
}

int query(int C) {
	int p = 0, res = 0;
	for (int i = 30; i >= 0; i--) {
		int u = (C >> i) % 2;
		if(son[p][!u]) { //如果有异或这一条路 
			p = son[p][!u]; //就异或 
			res = res * 2 + 1; //计算值 
		} else { //否则选择另一条路 
			p = son[p][u];
			res = res * 2 + 0;
		}
	}
	return res;
}

signed main() {
	cin >> n;
	for (int i = 1; i <= n; i++) cin >> a[i], insert(a[i]);
	for (int i = 1; i <= n; i++) ans = max(ans, query(a[i]));
	cout << ans << endl;
```

## [连通块中点的数量](https://www.acwing.com/problem/content/839/)

观察题目，我们可以发现，如果把第三个操作删除，那么与第一题没有任何区别，那我们能否在第一题的基础上稍稍改一下就行了呢？答案是当然可以的（后面讲堆的时候也会问道这个问题）。

定义数组 $siz$：$siz_i$ 表示根节点 $i$ 的集合的节点数量（我们只需要维护住根节点就可以了，其它的都是无意义）。

初始化：$siz_i=1$（刚开始只有自己一个点）。

修改：在合并操作时，设新集合根节点为 $y$，合并到 $y$ 下的集合为 $x$，则 $siz_y=siz_y+siz_x$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, m, ans, fa[maxn], siz[maxn];

}

void merger(int x, int y) { //合并 
    int xx = find(x), yy = find(y);
    if (xx != yy) fa[xx] = yy, siz[yy] += siz[xx];
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) //初始化

    	string opt;
```

## [食物链](https://www.acwing.com/problem/content/242/)

考虑到食物链中只有三种关系：同类、食物、天敌，因此使用并查集存储这些关系。

我们用 $1\sim n$ 表示 $x$ 的同类，$n+1\sim 2n$ 表示 $x$ 的食物，$2n+1\sim 3n$ 表示 $x$ 的天敌（当然也可以开三个并查集）

因此我们需要初始化并查集：

```cpp
for (int i = 1; i <= n * 3; i++) fa[i] = i; //需要开到三倍，因此需要n * 3
```

之后我们对题目的两种话的格式逐一判断：

- 如果 $x$ 和 $y$ 是同类。

这就要求了 $x$ 的食物和天敌不能是 $y$，如果保证这个条件，则合并 $x$ 的同类和 $y$ 的同类，$x$ 的食物和 $y$ 的食物，$x$ 的天敌和 $y$ 的天敌。因此可以写出以下代码：

```cpp
if (find(x + n) == find(y) || find(x + 2 * n) == find(y)) {  // x的食物或天敌不能是y
    ans++;
    continue;
}
merger(x, y), merger(x + n, y + n), merger(x + 2 * n, y + 2 * n);  //否则x的同类是y的同类，x的食物是y的食物，x的天敌是y的天敌
```

- 如果 $x$ 吃 $y$。

这就要求了 $x$ 的同类和天敌不能是 $y$，如果保证这个条件，则合并 $x$ 的同类和 $y$ 的天敌，$x$ 的食物和 $y$ 的同类，$x$ 的天敌和 $y$ 的食物。因此可以写出一下代码：

```cpp
if (find(x) == find(y) || find(x + 2 * n) == find(y)) {  // x的同类或天敌不能是y
    ans++;
    continue;
}
merger(x, y + 2 * n), merger(x + n, y), merger(x + 2 * n, y + n);  //否则，x的同类是y的天敌，x的食物是y的同类，x的天敌是y的食物
```

整合代码如下：

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, k, ans, fa[150010];
int find(int x) {
    if (x == fa[x]) return x;
    else {
        fa[x] = find(fa[x]);
        return fa[x];
    }
}//寻找

void merger(int x, int y) {
    int xx = find(x), yy = find(y);
    fa[xx] = yy;
}//合并

int main() {
    cin >> n >> k;
    for (int i = 1; i <= n * 3; i++)
        fa[i] = i;
    for (int i = 1; i <= k; i++) {
        int d, x, y; cin >> d >> x >> y;
        if (x > n || y > n) {
            ans++;
            continue;
        }
        if (d == 1) {
            if (find(x + n) == find(y) || find(x + 2 * n) == find(y)) { //x的天敌或猎物不能是y
                ans++;
                continue;
            }
            merger(x, y), merger(x + n, y + n), merger(x + 2 * n, y + 2 * n); //否则x的同类是y的同类，x的天敌是y的天敌，x的猎物是y的猎物
        } else {
            if (x == y) {
                ans++;
                continue;
            }
            if (find(x + n) == find(y) || find(x) == find(y)) { //x的天敌或同类不能是y
                ans++;
                continue;
            }
            merger(x, y + n), merger(x + n, y + 2 * n), merger(x + 2 * n, y); //否则，x的同类是y的天敌，x的天敌是y的猎物，x的猎物是y的同类
        }
    }
    cout << ans << endl;
    return 0;
}
```

# 堆

## [堆排序](https://www.acwing.com/problem/content/840/)

1. 堆的定义：

堆是具有以下性质的完全二叉树：每个结点的值都大于或等于其左右孩子结点的值， 这种情况称为大顶堆，注意:没有要求结点的左孩子的值和右孩子的值的大小关系。

每个结点的值都小于或等于其左右孩子结点的值， 这种情况称为小顶堆（大顶堆则反之）。

![](https://cdn.acwing.com/media/article/image/2022/06/11/55289_919d0ea7e9-20210320153049609.png)

![](https://cdn.acwing.com/media/article/image/2022/06/11/55289_3b2cf2fbe9-20210320153023354.png)

2. 堆的操作：

假设我们现在有这么一个堆，现在我要插入一个数字 $32$，那么我们应当怎么办呢？

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%874.png)

第一步，**置之不管**

不管怎么样，先创建一个新的节点（`++idx`），存下这个数再说。

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%875.png)

第二步，**这是我的**

创建完节点后，与自己的父节点进行比较；如果发现自己比父节点小，就进行交换位置，把自己的爹坑道自己那里。

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%872.png)

第三步，**适可而止**

如果发现自己的父节点小于等于自己，或者自己已经到了根节点了~~（就是说没有父亲了）~~，就适可而止，别乱动了。

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%872.png)

重复循环 $2$ 操作，直到 $3$ 操作，插入代码如下：

```cpp
void insert(int x) {
	has[++cnt] = x; //置之不管
    int k = cnt;
    while(k > 1 && has[k] < has[k / 2]) { //适可而止
    	swap(has[k], has[k / 2]); //这是我的
    	k /= 2; //来到自己父亲的位置
	}
}
```

----

假设我们现在想删除堆的最小的元素，应当怎么办呢？

第一步，**置之不管**

不管怎么样，先把最小的元素（也就是第一个元素）与最后一个元素（也就是 $has_{cnt}$）进行交换，且最后 $cnt-1$，当作把第一个点给删除了。

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%876.png)

第二步，**这是我的**

与自己的两个子节点进行比较，我们定义两个子结点中较小的哪个点的值为 $x$，如果发现自己大于 $x$，则对它进行交换，把自己坑到儿子那里。

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%877.png)

第三步，**适可而止**

如果发现自己比 $x$ 还小，或者说是已经没有子节点了~~（成单身狗了）~~，那么就适可而止，别乱动了。

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%878.png)

重复循环 $2$ 操作，直到 $3$ 操作，删除代码如下：

```cpp
void pop() {
    has[1] = has[cnt--]; //置之不管
	int k = 1;
	while(k * 2 <= cnt) { //适可而止
		if(k * 2 + 1 <= cnt && has[k * 2] < has[k * 2 + 1]) k = k * 2; //如果左儿子比右儿子小，则选择与左儿子交换
		else if(k * 2 + 1 <= cnt && has[k * 2] >= has[k * 2 + 1]) k = k * 2 + 1; //如果左儿子比右儿子大，则选择与右儿子交换
		//儿子相等的情况下，哪一边都可以交换
        else if(k * 2 <= cnt && k * 2 + 1 > cnt) k = k * 2; //只有一个儿子
		else return;
		if(has[k / 2] <= has[k]) return ; //发现较小的儿子都比自己大，就退出
		else swap(has[k], has[k / 2]); //否则交换
	}
}
```

当然也有递归实现：

```cpp
void pop() {
    has[1] = has[cnt--]; //置之不管
    int k = 1, t = 1;
    if(k * 2 <= cnt && has[k * 2] < has[t]) t = k * 2; //这是我的
    if(k * 2 + 1 <= cnt && has[k * 2 + 1] < has[t]) t = k * 2 + 1; //这是我的
    if(k != t) { //适可而止
        swap(has[k], has[t]);
        pop(t);
    }
}
```

---

由于堆头（$has_1$）是最小的，所以我们可以把 $n$ 个数插入堆中，之后每一次查询最小值都相当于查询堆头，然后删除堆头就行了。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m, cnt, ans, a[100010], has[100010];
void insert(int x) {
	has[++cnt] = x;
    int k = cnt;
    while(k > 1 && has[k] < has[k / 2]) {
    	swap(has[k], has[k / 2]);
    	k /= 2;
	}
}

void pop() {
    has[1] = has[cnt--];
	int k = 1;
	while(k * 2 <= cnt) {
		if(k * 2 + 1 <= cnt && has[k * 2] < has[k * 2 + 1]) k = k * 2;
		else if(k * 2 + 1 <= cnt && has[k * 2] >= has[k * 2 + 1]) k = k * 2 + 1;
		else if(k * 2 <= cnt && k * 2 + 1 > cnt) k = k * 2;
		else return;
		if(has[k / 2] <= has[k]) return ;
		else swap(has[k], has[k / 2]);
	}
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i], insert(a[i]);
    for (int i = 1; i <= m; i++) cout << has[1] << " ", pop();
    return 0;
}
```

## [模拟堆](https://acwing.com/problem/content/description/841/)

观察题目，我们可以发现，如果把第四、五个操作删除，那么与第一题没有任何区别，那我们能否在第一题的基础上稍稍改一下就行了呢？答案是当然不可以的（堆：你到老子是那**并查集啊！说改就改）。

回到题目，后两个操作都提到了"第 $k$ 个插入的数"，因此我们要开数组存下第 $k$ 个插入的数的 $idx$ 与在堆中的下标之间的关系（下标是会变的）。其中，定义 $ph_i$ 表示从 $idx$ 映射到下标，$hp_i$ 表示从下标映射到 $idx$。

那么，假设我们现在要交换下标为 $i$ 和 $j$ 的两个点，但我们的交换函数不再是简单的`swap`了，而是一个全新的交换函数了。

首先，原有的交换函数要留着，`swap(has[i], has[j])`（值要变）。

其次，它们下标变了，`swap(ph[hp[i]], ph[hp[j]])`（下标要变）。

最后，它们相同位置的下标对应的 $idx$ 变了，`swap(hp[i], hp[j])`（$idx$ 要变）。

代码如下：

```cpp 
void new_swap(int x, int y) {
    swap(has[x], has[y]); //首先，值换了
    swap(ph[hp[x]], ph[hp[y]]); //其次，代表的下标换了
    swap(hp[x], hp[y]); //最后，映射到的idx换了
}
```

因此，插入函数与删除函数也要变了：

```cpp
void insert(int k) { //这里的"置之不管"操作在主函数完成
    while(k > 1 && has[k] < has[k / 2]) {
    	new_swap(k, k / 2);
    	k /= 2;
	}
}

void pop(int k) { //这里的"置之不管"操作在主函数完成
    int t = k;
    if(k * 2 <= cnt && has[k * 2] < has[t]) t = k * 2;
    if(k * 2 + 1 <= cnt && has[k * 2 + 1] < has[t]) t = k * 2 + 1;
    if(k != t) {
        new_swap(k, t);
        pop(t);
    }
}
```

---

现在一个一个操作来看：

`top1`：

1. 首先开辟新空间，`cnt++, m++ //cnt指下标，m指idx`
2. 创立新结点，`ph[m] = cnt, hp[cnt] = m, has[cnt] = x`
3. 保持堆的正常运转，`insert(cnt)`

`top2`：

直接查询堆头就行了，`cout << has[1] << endl`

`top3`：

1. 删除原节点：`new_swap(1, cnt), cnt--`
2. 保持堆的正常运转，`pop(1)`

`top4`：

1. 找到第 $k$ 个数的下标，`cin >> x; int k = ph[x]`
2. 删除原节点，`new_swap(k, cnt), cnt--`
3. 保持堆的正常运转，`insert(k), pop(k)`

`top5`：

1. 找到第 $k$ 个数的下标，`cin >> x >> y; int k = ph[x]`
2. 修改原节点，`has[k] = y`
3. 保持堆的正常运转，`insert(k), pop(k)`

整体代码：

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, m, cnt, has[maxn], ph[maxn], hp[maxn]; //ph表示从idx映射到下标，hp则反之
void new_swap(int x, int y) {
    swap(has[x], has[y]); //首先，值换了
    swap(ph[hp[x]], ph[hp[y]]); //其次，代表的下标换了
    swap(hp[x], hp[y]); //最后，映射到的idx换了
}

void insert(int k) {
    while(k > 1 && has[k] < has[k / 2]) {
    	new_swap(k, k / 2);
    	k /= 2;
	}
}

void pop(int k) {
    int t = k;
    if(k * 2 <= cnt && has[k * 2] < has[t]) t = k * 2;
    if(k * 2 + 1 <= cnt && has[k * 2 + 1] < has[t]) t = k * 2 + 1;
    if(k != t) {
        new_swap(k, t);
        pop(t);
    }
}

int main() {
    cin >> n;
    while(n--) {
        string opt;
        int x, y;
        cin >> opt;
        if(opt == "I") {
            cin >> x;
            cnt++, m++; //cnt指下标，m指idx
            ph[m] = cnt, hp[cnt] = m;
            has[cnt] = x;
            insert(cnt);
        }
        else if(opt == "PM") cout << has[1] << "\n";
        else if(opt == "DM") {
            new_swap(cnt, 1);
            cnt--;
            pop(1);
        }
        else if(opt == "D") {
            cin >> x;
            int k = ph[x]; //映射到下标
            new_swap(k, cnt--);
            insert(k), pop(k); //这里的insert与pop只是为了使这个堆有序，并非插入或删除
        }
        else if(opt == "C") {
            cin >> x >> y;
            int k = ph[x];
            has[k] = y;
            insert(k), pop(k); //这里的insert与pop只是为了使这个堆有序，并非插入或删除
        }
    }
    return 0;
}
```

# 哈希表

## [模拟散列表](https://www.acwing.com/problem/content/842/)

**什么是哈希表**

哈希表，是一种通过哈希函数得到值并储存起来的一种**数据结构**，哈希函数（`Hash(x)`）的特点如下：

1. 能缩小值域
2. 相同的数传进去返回相同的数
3. 不同的数传进去返回不同的数

哈希表，一般是通过一个类似邻接表一样的东西来储存元素的，就是这样`vector<int> h[maxn]`。

在这题，我们的哈希函数可以通过取模 $200003$ 来返回，像这样：

```cpp
void Hash(int x) {
    return (x % 200003 + 200003) % 200003;
}
```

每次我们通过哈希函数得到一个值，都会由对应的下标放入里面，具体如下：

```cpp
void insert(int k) {
    int x = Hash(k);
    for (auto i:h[x]) //对应下标
        if(i == k) return ; //有就不用加入
    h[x].push_back(k); //否则装进表里
}
```

当然我们也需要查询某个数是否存在，方法差不多，具体如下：

```cpp
int find(int k) {
    int x = Hash(k);
    for (auto i:h[x]) //对应下标
        if(i == k) return 1; //有
    return 0; //没有
}
```

整体代码如下：

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define mod 200003
using namespace std;

int n;
vector<int>h[mod];
int find(int k) {
    int x = (k % mod + mod) % mod;
    for (auto i:h[x]) if(i == k) return 1;
    return 0;
}

void insert(int k) {
    int x = (k % mod + mod) % mod;
    for (auto i:h[x]) if(i == k) return ;
    h[x].push_back(k);
}

int main() {
    cin >> n;
    while(n--) {
        string opt;
        int x;
        cin >> opt >> x;
        if(opt == "I") insert(x);
        else cout << (find(x) ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

## [字符串哈希](https://www.acwing.com/problem/content/843/)

全称字符串前缀哈希法，把字符串变成一个 $p$ 进制数字（哈希值），实现不同的字符串映射到不同的数字。

对形如 $X_1,X_2,X_3...X_{n-1},X_n$ 的字符串，采用字符的 $ASCLL$ 码乘上 $p$ 的次方来计算哈希值。

映射公式 $(X_1×P^{n−1}+X_2×P^{n−2}+⋯+X_n−1×P^1+X_n×P^0)\bmod Q$

注意点：
1. 任意字符不可以映射成 $0$，否则会出现不同的字符串都映射成 $0$ 的情况，比如 $\texttt{A,AA,AAA}$ 皆为 $0$。
2. 冲突问题：通过巧妙设置 $p$（$131$ 或 $13331$）,$Q$ （$2^{64}$）的值，一般可以理解为不产生冲突。

问题从比较不同区间的子串是否相同，就转化为对应的哈希值是否相同。

求一个字符串的哈希值就相当于求前缀和，求一个字符串的子串哈希值就相当于求部分和。

在这里，我们设 $h_i$ 为前 $i$ 位的字符串的哈希值，$p_i$ 则表示 $p^i\bmod Q$，$C$ 表示整个字符串；于是 $h_i=h_{i-1}\times p+C_i,p_0=1,p_i=p_{i-1}\times p\bmod Q$。

前缀和已经准备好，那如何使用呢？

![](http://dyoi.net:2024/file/873/%E9%A2%98%E8%A7%A3%E9%9C%80%E8%A6%81%E5%9B%BE%E7%89%8710.png)

所以，$h[l-1\sim r]=h_r-h_{l-1}\times q^{r-l+1}$。

最后提供一个小技巧，`unsigned long long`溢出相当于 $\bmod 2^{64}$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define mod 200003
#define int unsigned long long //相当于% 2^64 
using namespace std;

const int P = 131;
int n, m, p[maxn], h[maxn];
char C[maxn];
int get(int l, int r) {
    return h[r] - h[l - 1] * p[r - l + 1]; //哈希 
}

signed main() {
    cin >> n >> m >> (C + 1);
    p[0] = 1;
    for (int i = 1; i <= n; i++) {
        p[i] = p[i - 1] * P;
        h[i] = h[i - 1] * P + C[i]; //转换为P进制 
    }
    while(m--) {
        int l1, r1, l2, r2;
        cin >> l1 >> r1 >> l2 >> r2;
        cout << (get(l1, r1) == get(l2, r2) ? "Yes" : "No") << "\n";
    }
    return 0;
}
```
