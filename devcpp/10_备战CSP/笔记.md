## [第一题](https://www.luogu.com.cn/problem/P2141)

### 题目大意

给定一个序列，问有多少个数，恰好等于集合中另外两个（不同的）数之和。

### 题目思路

首先枚举元素 $k$，其次再枚举元素 $i$ 和元素 $j$，如果 $i+j=k，\text{则}\ ans+1$。

不过需要注意一点：

> 他是问**有多少个数**，恰好等于集合中另外两个（不同的）数之和。
>
> 没问你集合中有多少组数的和等于集合中的另一个数。

代码如下：

```cpp
#include <bits/stdc++.h>
#define maxn 110
#define int long long
using namespace std;

int n, ans, cnt[100010], a[maxn];
bool is(int x) { //判断是否有两个数相加等于a[x] 
	for (int i = 1; i <= n; i++) {
		if(i == x) continue; //不能等于x 
		for (int j = i + 1; j <= n; j++) {
			if(j == x) continue; //同理
			if(a[i] + a[j] == a[x]) return true; //如果有答案，则返回true 
		}
	}
	return false;
}

signed main() {
	cin >> n;
	for (int i = 1; i <= n; i++) cin >> a[i];
	sort(a + 1, a + n + 1); //其实我也不知道这个排序是干嘛的，但是有不敢删...... 
	for (int k = 1; k <= n; k++)
		if(is(k)) ans++; //如果有答案，则ans++ 
	cout << ans << endl;
	return 0;
}
```

## [第二题](https://www.luogu.com.cn/problem/P2118)

### 题目大意

给定一个比例 $a:b$，存在一个比例 $x:y$，使得 $x\ \text{与}\ y\ \text{互质}，x\le l，y\le l$，并且 $x:y$ 的值 $\ge a:b$，求出最小的 $x\ \text{和}\ y$。

### 题目思路

观察数据范围：$l \le 100$，可以直接暴力枚举 $x\ \text{和}\ y$。

判断 $x、y$ 是否互质：$(x,y)=1$。

判断 $x:y\ge a:b$，可以使用浮点型变量存储进行比较，不过那样过于麻烦。可以采用交叉相乘法：$\frac{x}{y}\ge \frac{a}{b}=xb\ge ya$。

上代码：

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int A, B, L;
int gcd(int x, int y) { //求最大公约数 
	if(y == 0) return x;
	return gcd(y, x % y);
}

signed main() {
	cin >> A >> B >> L;
	int ansa = L, ansb = 1; //初始化，记录最优解 
	for (int i = 1; i <= L; i++)
		for (int j = 1; j <= L; j++)
			if(gcd(i, j) == 1 && i * B >= A * j && ansa * j > ansb * i) ansa = i, ansb = j; //判断条件 
	cout << ansa << " " << ansb << endl;
	return 0;
}
```

## [第三题](https://www.luogu.com.cn/problem/P2239)

### 题目大意

给定一个 $n$ 行 $n$ 列的螺旋矩阵，求一个螺旋矩阵中某个位置的值。

例如下图就是是 $n=4$ 的螺旋矩阵：
$$
\begin{pmatrix}
1 & 2 & 3 & 4 \\
12 & 13 & 14 & 5 \\
11 & 16 & 15 & 6 \\
10 & 9 & 8 & 7 \\
\end{pmatrix}
$$

### 题目思路

$\large\text{暴力}$

可以一步一步的枚举，以达到枚举完所有的位置，其中 $l$ 表示左上角的列数，$u$ 表示左上角的行数，$r$ 表示右下角的列数，$q$ 表示右下角的行数，如果左上角和右下角的列数相碰，则说明枚举完毕了。当然也可以写成如果 $sum = n^2$，则退出（其实这个暴力也很难写）：

```cpp
#include <bits/stdc++.h>
#define maxn 30010
using namespace std;

int n, i, j, a[maxn][maxn];
long long ans;
int main() {
    scanf("%d%d%d", &n, &i, &j);
    int l = 1, u = 1, r = n, q = n, sum = 0;
    while(l <= r) {
        for (int k = l; k <= r; k++) a[u][k] = ++sum;
        for (int k = u + 1; k <= q; k++) a[k][r] = ++sum;
        for (int k = r - 1; k >= l; k--) a[q][k] = ++sum;
        for (int k = q - 1; k >= l + 1; k--) a[k][l] = ++sum;
        l++, r--, u++, q--;
    }
	cout << a[i][j] << endl;
    return 0;
}
```

但是很明显，空间会炸掉，所以我们可以不需要用数组模拟：

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, i, j;
long long ans;
int main() {
    scanf("%d%d%d", &n, &i, &j);
    int l = 1, u = 1, r = n, q = n, sum = 0;
    while(l <= r) {
        for (int k = l; k <= r; k++) {
            ++sum;
            if(u == i && k == j) {
                cout << sum << endl;
                return 0;
            }
        }
        for (int k = u + 1; k <= q; k++) {
            ++sum;
            if(k == i && r == j) {
                cout << sum << endl;
                return 0;
            }
        }
        for (int k = r - 1; k >= l; k--) {
            ++sum;
            if(q == i && k == j) {
                cout << sum << endl;
                return 0;
            }
        }
        for (int k = q - 1; k >= l + 1; k--) {
            ++sum;
            if(k == i && l == j) {
                cout << sum << endl;
                return 0;
            }
        }
        l++, r--, u++, q--;
    }
    return 0;  
}
```

可惜时间还是会炸掉，所以考虑新方法！

$\large\text{递归}$

可以利用打表找规律，如下表（$n=5$ 的情况）

|  1   |  2   |  3   |  4   |  5   |
| :--: | :--: | :--: | :--: | :--: |
|  16  |  17  |  18  |  19  |  6   |
|  15  |  24  |  25  |  20  |  7   |
|  14  |  23  |  22  |  21  |  8   |
|  13  |  12  |  11  |  10  |  9   |

观察一下规律，跟着数字增长的方向走，不难发现：

1. 如果是第 $1$ 行，第 $j$ 列，则数字为 $j$；
2. 如果是第 $i$ 行，第 $n$ 列，则数字为 $n + i - 1$；

后两条规律有点难找，但是耐性找一下，继续观察：

3. 如果是第 $n$ 行，第 $j$ 列，则数字为 $3\cdot n - j - 1$；
4. 如果是第 $i(i\ne 1)$ 行，第 $1$ 列，则数字为 $4\cdot n - i - 2$；

好，现在对于每一种情况，我们都推出了一个公式。现在画一个 $6\times 6$ 的螺旋矩阵，验证一下，会发现完全正确：

|  1   |  2   |  3   |  4   |  5   |  6   |
| :--: | :--: | :--: | :--: | :--: | :--: |
|  20  |  21  |  22  |  23  |  24  |  7   |
|  19  |  32  |  33  |  34  |  25  |  8   |
|  18  |  31  |  36  |  35  |  26  |  9   |
|  17  |  30  |  29  |  28  |  27  |  10  |
|  16  |  15  |  14  |  13  |  12  |  11  |

推导完公式，剩下的就简单多了。不难想出一个**递归**解法：把螺旋矩阵一层一层地剖开，看看目标位置在哪一层，然后加上这一层的数字个数 $4(n-1)$，即为要求的数字。

上代码：

```cpp
#include <bits/stdc++.h>
using namespace std;

int work(int n, int i, int j) {
	if(i != 1 && j != 1 && i != n && j != n) return 4 * (n - 1) + work(n - 2, i - 1, j - 1); //如果要找到数不在这一层，则进行递归（注意：由于我们是一层一层的剖开，所以n-2） 
	if(i == 1) return j; //第1行，第j列 
	if(j == n) return n + i - 1; //第i行，第n列 
	if(i == n) return 3 * n - j - 1; //第n行，第j列 
	if(j == 1 && i != 1) return 4 * n - i - 2; //第i(i!=1)行，第一列 
}

int n, i, j;
int main() {
	cin >> n >> i >> j;
	cout << work(n, i, j) << endl;
	return 0;
}
```

## [第四题](https://www.luogu.com.cn/problem/P2258)

### 题目大意

给定一个矩阵，从中取出 $r$ 行和 $c$ 列，把它们相交的部分取出来，按照原来的顺序构成一个新的矩阵。每一个子矩阵的分值：矩阵中每一对相邻元素之差的绝对值之和。请求出最小分值。

### 题目思路

首先打出暴力，即先枚举行的取法，再枚举列的取法，然后对其进行如题目所述般的处理，最后取所有情况的最小值（而且还能进行剪枝优化）。

代码如下（暴力拿下 $70$ 分！！！）：

```cpp
#include <bits/stdc++.h>
#define maxn 20
#define min(x, y) x < y ? x : y //三目运算符更快
using namespace std;

int n, m, r, c, ans = 1e9, cnthang, cntlie, a[maxn][maxn], hang[maxn], lie[maxn], temp[maxn][maxn];
void dfs2(int l) {
	if(cntlie == c) { //枚举列的取法
		int sum = 0;
		for (int i = 1; i <= r; i++)
			for (int j = 1; j <= c; j++)
				temp[i][j] = a[hang[i]][lie[j]]; //构建子矩阵
		for (int i = 1; i <= r; i++)
			for (int j = 1; j < c; j++)
				sum += abs(temp[i][j] - temp[i][j + 1]); //算出相邻列的分值
		for (int i = 1; i < r; i++)
			for (int j = 1; j <= c; j++)
				sum += abs(temp[i][j] - temp[i + 1][j]); //算出相邻行的分值
		ans = min(ans, sum); //更新答案
		return;
	}
	if(m - l + 1 + cntlie < c) return; //剪枝，如果即使剩下的列全都取了也不能达到c，则return
	lie[++cntlie] = l; //加入列取法数组
	dfs2(l + 1); //下一轮搜索
	lie[cntlie--] = 0; //回溯
	dfs2(l + 1); //不加入
}

void dfs1(int h) { //枚举行的取法
	if(cnthang == r) { //取完了
		dfs2(1); //则枚举列的取法
		return;
	}
	if(n - h + 1 + cnthang < r) return; //剪枝，如果即使剩下的行全都取了也不能达到r，则return
	hang[++cnthang] = h; //加入行取法数组
	dfs1(h + 1); //下一轮搜索
	hang[cnthang--] = 0; //回溯
	dfs1(h + 1); //不加入
}

int main() {
	scanf("%d%d%d%d", &n, &m, &r, &c);
	for (int i = 1; i <= n; i++)
		for (int j = 1; j <= m; j++)
			scanf("%d", &a[i][j]);
	dfs1(1);
	printf("%d\n", ans); 
	return 0;
}
```

但是，这样的最高时间复杂度为 $O(C(n,n/2)^2n^2)$，对于所有数据，可能的最大运算总数是 $C(16,8)^2\times8^2$，本人计算了一下，大约已经有三百亿了（注意后面那个 $n^2$，它是处理每一个情况时所花的时间复杂度）。

很多人因此止步，是因为都在想着正解会不会是根本不用枚举情况，直接 $O(n^k)$（$k$ 不知道是多少……）DP就搞定了。那我告诉各位，正解其实还是要枚举的……所以，这里一定要注意，不要被传统的 DP 形式坑了。

做法的结构大致是这样的：首先枚举其行的排列情况。然后，对于每一种行的排列情况，DP 出它列的最优情况（DP 等会儿再讲），然后取所有行的排列情况的最优情况的最小值。这样，就只需要一维的枚举了，比暴力快了不少。有的人可能还会问，这样会不会也超时？我们来算一下。这样的结构时间复杂度是：$O(C(n,n/2)n^3)$，其中 $C(n,n/2)$ 是一维枚举的时间复杂度，$n^3$ 是 DP 的时间复杂度。那么，对于所有数据，它最多的运算次数是：$C(16,8)\times16^3$，大约是五千万，是可以通过的。所以只要把细节打出来，此题就过了。

那么，具体的算法如何实现呢？首先，枚举就不用讲了（代码里会讲到一点优化剪枝），然后就是 DP 的事了。问题就在于如何 DP 呢？其实，我们可以针对每一种枚举出来的行的情况都进行一次类似的 DP。而针对于每一种情况，我们可以把它抽象化成一个更简单的问题：一个 $r\times m$ 矩阵，选择 $c$ 列，问其相邻元素的差的绝对值的和最小是多少？在这个 $r\times m$ 的矩阵中，那 $r$ 行其实就是我们已经枚举出来的几行，而 $m$ 和 $c$ 与原题中的 $m$ 和 $c$ 相同，从而将二维选择的问题降至了一维。

而 DP 也变得十分明显了：设 `f[i][j]` 表示在这个 $r\times m$ 的矩阵中，在其前 $i$ 列中选择 $j$ 列（且选的列中包括第 $i$ 列），组成的子矩阵中，最小值（即其相邻元素的差的绝对值的和的最小值（之后的值等表达也是指的这个东西，即题目要求求出的值））是多少。这样，便可以很显然的推出动态转移方程：

`f[i][j] = min(f[k][j - 1] + h[i] + l[k][i])`

这里的 `h[i]` 指的是第 $i$ 列中所有元素的分值，`l[i][j]` 指的是仅对于第 $i$ 列与第 $j$ 列之间，所有同行元素的差的绝对值的和。而求 `h` 和 `l` 也很简单，只要在 DP 之前进行预处理即可。

边界条件也是需要格外注意的。首先是 $k$，$k$ 的取值范围是从 $j-1$ 到 $i-1$。$i-1$ 很好理解，就是枚举前 $i-1$ 个，之后加上自己。而 $j-1$ 是因为若 $k$ 小于 $j-1$，则 $k<j-1$，`f[k][j-1]` 这个状态也就自然不存在了（从定义上很好理解）。所以得出了 $k$ 的取值范围。

另外需要注意的是边界情况，有两个边界：

1. 第一个是 $j=1$ 的情况，此时`f[i][j] = lc[i]`

2. 第二个是 $j = i$ 的情况，即前 $i$ 列都取，所以 `f[i][j] = f[i - 1][j - 1] + h[i] + l[j - 1][i]`。将 DP 写好，此题便处理完成了。

> 其实 DP 题很容易被看出来，但是总是因为 DP 的变换莫测难以入手。所以，一定要好好地练 DP。 ----chrispang

```cpp
#include <bits/stdc++.h>
#define maxn 20
#define min(x, y) x < y ? x : y //三目运算符更快
#define inf 1e8
using namespace std;

int n, m, r, c, ans = 1e9, cnthang, a[maxn][maxn], hang[maxn], f[maxn][maxn], h[maxn], l[maxn][maxn];
void mems() {
	memset(h, 0, sizeof(h)); //初始化 
	memset(l, 0, sizeof(l)); //初始化 
	for (int i = 1; i <= m; i++)
		for (int j = 1; j < r; j++)
			h[i] += abs(a[hang[j]][i] - a[hang[j + 1]][i]); //算出这一列所有元素的分值 
	for (int i = 1; i <= m; i++)
		for (int j = i + 1; j <= m; j++) //这里i < j 
			for (int k = 1; k <= r; k++)
				l[i][j] += abs(a[hang[k]][i] - a[hang[k]][j]); //求出第i列与第j列之间, 所有同行元素的差的绝对值的和
}

void dp() {
	mems();
	for (int i = 1; i <= m; i++)
		for (int j = 1, minc = min(i, c); j <= minc; j++) { //先求出j的上限 
			if(j == 1) f[i][j] = h[i]; //边界条件1
			else if(i == j) f[i][j] = f[i - 1][j - 1] + h[i] + l[j - 1][i]; //边界条件2 
			else { //正常情况 
				f[i][j] = inf; //赋上inf 
				for (int k = j - 1; k <= i - 1; k++) //注意k的边界
					f[i][j] = min(f[i][j], f[k][j - 1] + h[i] + l[k][i]);//取最小值
			}
			if(j == c) ans = min(ans, f[i][c]); //存在此状态，则更新最小值 
		}
}

void dfs(int x) { //这里就是枚举行的取法 
	if(cnthang == r) { //取完了
		dp();
		return;
	}
	if(n - h + 1 + cnthang < r) return; //剪枝，如果即使剩下的行全都取了也不能达到r，则return
	hang[++cnthang] = h; //加入行取法数组
	dfs1(h + 1); //下一轮搜索
	hang[cnthang--] = 0; //回溯
	dfs1(h + 1); //不加入
}

signed main() {
	scanf("%d%d%d%d", &n, &m, &r, &c);
	for (int i = 1; i <= n; i++)
		for (int j = 1; j <= m; j++)
			scanf("%d", &a[i][j]);
	dfs(1);
	printf("%d\n", ans);
	return 0;
}
```

## [第二题](https://www.luogu.com.cn/problem/P2670)

### 题目大意

给出 $n$ 行 $m$ 列的雷区中的地雷分布，要求计算出每个非地雷格周围的地雷格数（一个格子的周围格子包括其上、下、左、右、左上、右上、左下、右下八个方向上与之直接相邻的格子）。

### 题目思路

笑点分析：由于这道题太简单了，导致我之前刷水体的时候已经做过了。

其实就是模拟：找到一个地雷，将周围的数加起来。

但是需要注意几点（其实就是不知道该写点什么了）：

1. 方位数组要写好，不要错了；
2. 不能越界，否则自己看着办：
3. 最后输出答案的时候要注意此地是否有雷。

```cpp
#include <bits/stdc++.h>
#define maxn 110
using namespace std;

int n, m, ans[maxn][maxn]; //最后的答案
char a[maxn][maxn]; //输入的矩阵 
int dx[8] = {1, 1, 1, 0, 0, -1, -1, -1}; //方位数组 
int dy[8] = {-1, 0, 1, -1, 1, -1, 0, 1};
int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> a[i][j];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (a[i][j] == '*') //如果这个地方是雷
                for (int k = 0; k < 8; k++) { //遍历八个方向 
                	int x = i + dx[k], y = j + dy[k]; //找到附近的位置 
                	if (a[x][y] != '*') ans[x][y]++; //如果附近不是雷，则答案+1 
				}
    for (int i = 1; i <= n; i++, puts(""))
        for (int j = 1; j <= m; j++)
            if(a[i][j] != '*') cout << ans[i][j]; //注意这个地方不能有雷 
            else cout << '*';
    return 0;
}
```

## [第三题](https://www.luogu.com.cn/problem/P2671)

### 题目大意

定义一种特殊的三元组：$(x,y,z)$，其中 $x,y,z$ 都代表纸带上格子的编号，这里的三元组要求满足以下两个条件：

> 1. $x,y,z$ 都是整数，$x<y<z,y−x=z−y$。
> 2. $x,z$ 颜色相同。

满足上述条件的三元组的分数规定为 $(x+z)\times(number_x+number_z)$。

求所有三元组的分值的和 $\%10007$ 的结果。

### 题目思路

首先先打出暴力，分别枚举 $x,y,z$，时间复杂度 $O(n^3)$（能拿 $20$ 分）。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define mod 10007
#define int long long
using namespace std;

int n, m, ans, number[maxn], color[maxn];
signed main() {
	cin >> n >> m;
	for (int i = 1; i <= n; i++) cin >> number[i];
	for (int i = 1; i <= n; i++) cin >> color[i];
	for (int x = 1; x <= n; x++)
		for (int y = x + 1;  y <= n; y++)
			for (int z = y + 1; z <= n; z++)
				if(y - x == z - y && color[x] == color[z])
					ans = (ans + (x + z) * (number[x] + number[z])) % mod;
	cout << ans << endl;
	return 0;
}
```

诶，我们发现，这个「分数」跟 $y$ 之间，怎么半个咕值的关系都没有啊 $\text{QAQ}$ ？

于是，秒懂![/xyx](https://cdn.luogu.com.cn/upload/pic/62230.png)：
$$
∵ y-x=z-y \\
∴ x+z=2y
$$
又 $2y$ 是偶数，所以 $x,z$ 同奇偶。

这就是 $y$ 的作用啦！

----

经过分析，发现 $y$ ~~屁用没有~~没有用，所以直接枚举 $x$ 和 $z$ 就可以了。时间复杂度 $O(n^2)$（能拿 $50$ 分）

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define mod 10007
#define int long long
using namespace std;

int read() {
	int x = 0, f = 1;
	char ch = getchar();
	while(ch < '0' || ch > '9') f *= (ch == '-' ? -1 : 1), ch = getchar();
	while(ch >= 48 && ch <= 57) x = (x << 1) + (x << 3) + (ch ^ 48), ch = getchar();
	return x * f;
}

void write(int x) {
	if(x < 0) putchar('-'), x = -x;
	if(x > 9) write(x / 10);
	putchar(x % 10 ^ 48);
}

int n, m, ans;
struct node {
	int number, color;
}a[maxn];

signed main() {
	n = read(), m = read();
	for (int i = 1; i <= n; i++) a[i].number = read();
	for (int i = 1; i <= n; i++) a[i].color = read();
	for (int x = 1; x <= n; x++)
		for (int z = x + 2; z <= n; z += 2) //为了保持奇偶性一致，每次都加2 
			if(a[x].color == a[z].color) ans = (ans + (x + z) * (a[x].number + a[z].number)) % mod;
	write(ans);
	return 0;
}
```

----

虽然快了不少（从 $O(n^3)$ 变成 $O(n^2)$），可惜复杂度还是吃不消。

可从中发现由于每次都要查找一遍，导致会又很多重复的计算，那么我们能否不再重复这一遍又一遍的操作呢？

我们可以打表找规律，比如我们定义 $a_1,a_2,a_3$，它们奇偶性相同，且颜色也相同。

那么答案 $=(a_1+a_2)\times(number_1+number_2) + (a_1+a_3)\times(number_1+number_3) + (a_2+a_3)\times(number_2+number_3)$

而 $a_1$ 对答案的贡献为 $a_1\times(number_1+number_2)+a_1\times(number_1+number_3)=a_1\times(number_1 + number_1+number_2+number_3)$

我们可以发现，$a_1$ 对答案的贡献等于 $a_1\times(number_1 \times (n-2)+\text{数字和})(\text{n\ 是同样奇偶性相同、颜色相同的数的各数，且含自己。}\text{数字和是同样奇偶性相同、颜色相同的数的和})$

那么 $a_k$ 对答案的贡献等于 $a_k\times(number_k \times (n-2)+\text{数字和})$。

而其中的 $n$ 和 $\text{数字和}$ 都是可以提前预处理出来的，所以时间复杂度为 $O(n)$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define mod 10007
#define int long long //改成long long,这样只需要在最后 % mod就好了 
using namespace std;

int n, m, ans, cnt[maxn][2], sum[maxn][2]; //cnt[i][j]表示颜色为i,下标[%2=j]的数的数量,sum[i][j]表示颜色为i,下标[%2=j]的数的总和 
struct node {
	int number, color;
}a[maxn];

signed main() {
	cin >> n >> m;
	for (int i = 1; i <= n; i++) cin >> a[i].number;
	for (int i = 1; i <= n; i++) cin >> a[i].color;
	for (int i = 1; i <= n; i++) {
		cnt[a[i].color][i & 1]++; //计算数量 
		sum[a[i].color][i & 1] += a[i].number; //计算总和 
	}
	for (int x = 1; x <= n; x++)
		ans += x * ((cnt[a[x].color][x & 1] - 2) * a[x].number + sum[a[x].color][x & 1]); //计算公式 
	cout << ans % mod << endl; //最后答案 % mod 
	return 0;
}
```

## [第四题](https://www.luogu.com.cn/problem/P2672)

### 题目大意

推销员阿明，要给住在某街的 $N$ 个用户推销，**走一米会增加 $1$ 的疲劳值**，第 $i$ 家距离路口 $s_i$ 米(**可能会有重复的** $s_i$)给第 $i$ 家推销会增加 $a_i$。全部推销完，**还要原路返回。**

现在，依次向 $X$ 用户推销，对于不同的 $x$，阿明想知道**最大疲劳值。**

### 题目思路

考虑贪心：每次选取最大疲劳值，之后累加起来，本题就~~随随便便~~做完了。

但是因为有这个“距离”，导致了我们的计算变得复杂了，所以我们可以进行分别考虑：

1. 首先，先把第一次的答案计算出来，设第一次的答案的**推销产品**疲劳度为 $sum$ 、位置（即对应的 $s$ 值）为 $maxs$。
2. 接着进行遍历，如果这个点没有被访问过，且 $s_i\ge maxs$，那么检查 $sum + a_i + s_i \times 2> newsum + news \times 2$，如果是，则更新 $newsum\text\ {和}\ news$。
3. 如果这个点没有被访问过，且 $s_i<maxs$，那么检查 $sum + a_i + maxs \times 2> newsum + news \times 2$，如果是，则更新  $newsum\text\ {和}\ news$。
4. 循环 $2、3$ 步骤 $n-1$ 次，并且输出答案。

代码如下（ $60$ 分）：

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define int long long //养成好习惯，开就对了
using namespace std;

int read() { //快读
	int x = 0, f = 1;
	char ch = getchar();
	while(ch < '0' || ch > '9') f *= (ch == '-' ? -1 : 1), ch = getchar();
	while(ch >= 48 && ch <= 57) x = (x << 1) + (x << 3) + (ch ^ 48), ch = getchar();
	return x * f;
}

void write(int x) { //快写
	if(x > 9) write(x / 10);
	putchar(x % 10 ^ 48);
}

int n, maxs, sum, pos, S[maxn], A[maxn];
bool vis[maxn];
signed main() {
	n = read();
	for (int i = 1; i <= n; i++) S[i] = read();
	for (int i = 1; i <= n; i++) A[i] = read();
    for (int i = 1; i <= n; i++) if(S[i] * 2 + A[i] > sum + maxs * 2) sum = A[i], maxs = S[i], pos = i; //找到最大值，并且记录答案
    vis[pos] = 1; //进行标记
    write(sum + maxs * 2); //注意这里不是输出sum，因为sum的定义是推销产品的疲劳度，还要加上maxs*2(跑了两趟)
	putchar('\n');
	for (int k = 1; k < n; k++) {
		int new_sum = sum, new_s = maxs, newpos = 0; //初始化
		for (int i = 1; i <= n; i++)
			if(vis[i] == 0) { //如果这个点没有被访问过
				if(S[i] >= maxs && sum + A[i] + S[i] * 2 > new_sum + new_s * 2) new_sum = sum + A[i], new_s = S[i], newpos = i; //如果满足条件，则更新
				else if(S[i] < maxs && sum + A[i] + maxs * 2 > new_sum + new_s * 2) new_sum = sum + A[i], new_s = maxs, newpos = i; //同上
			}
		sum = new_sum, maxs = new_s, vis[newpos] = 1; //把得到的值复原回原来的值
		write(sum + maxs * 2); //输出
		putchar('\n');
	}
    return 0;
}
```

贪心思路是对的，可惜查询时间太慢了，所以时间复杂度为 $O(n^2)$。

如何加快查询时间呢？可以考虑这三种数据结构：优先队列、树状数组、线段树。

由于我想写点挑战性的，所以我选择了线段树（呵呵）。

----

$\Large \text{怎么用线段树}$

每次查询最大值都查询 $1\sim pos-1$ 的最大值和 $pos+1\sim n$ 的最大值，其中 $pos$ 是当前选中的推销用户中距离起点最大的点的下标。

$\Large\text{怎么写}$

$\large\text{定义}$

我们把线段树分成两种，`node1` 和 `node2`，`node1` 表示不考虑距离情况下的区间最大值，`node2` 则表示考虑距离情况下的区间最大值。

而 `node1` 由 $sum\ \text{和}\ pos$ 组成，即区间最大疲劳度和选中的推销用户，而 `node2` 只是比 `node1` 多了一个 $maxs$，作用是求出选中的推销用户与起点的距离。

```cpp
struct node1 {
	int sum, pos;
}maxv1[maxn * 4]; //线段树的空间一般都要*4

struct node2 {
	int sum, maxs, pos;
}maxv2[maxn * 4];
```

$\large\text{pushup 函数的写法}$

`maxv1` 的更新：由于 `maxv1` 只涉及到了**推销用户**的疲劳度，所以比较 `maxv1[id * 2]` 和 `maxv1[id * 2 + 1]`，谁的 `sum` 值大就选谁。

`maxv2` 的更新：其实就是算上了距离，本质上与 `maxv1` 的更新操作没什么太大的区别。

```cpp
void pushup(int id) {
	maxv1[id] = maxv1[id * 2].sum > maxv1[id * 2 + 1].sum ? maxv1[id * 2] : maxv1[id * 2 + 1]; //只考虑推销用户的疲劳度 
	maxv2[id] = maxv2[id * 2].sum + maxv2[id * 2].maxs * 2 > maxv2[id * 2 + 1].sum + maxv2[id * 2 + 1].maxs * 2 ? maxv2[id * 2] : maxv2[id * 2 + 1]; //加上了距离 
}
```

$\large\text{build 函数的写法}$

`maxv1` 的构造：由于只涉及到了**推销用户**的疲劳度，所以初始化为 `a[l]` 和 `l`（$sum$ 和 $pos$）。

`maxv2` 的构造：比 `maxv1` 只加上了距离，所以初始化为 `a[l]`，`s[l]`（注意这里不要写成 `s[l]*@`）,`l`（$sum、maxs$ 和 $pos$）。

```cpp
void build(int id, int l, int r) {
	if(l == r) {
		maxv1[id] = {A[l], l}; //构建maxv1 
		maxv2[id] = {A[l], S[l], l}; //构建maxv2 
		return ;
	}
	int mid = (l + r) >> 1;
	build(id * 2, l, mid);
	build(id * 2 + 1, mid + 1, r);
	pushup(id); //回来时需要更新 
}
```

$\large\text{update 函数的写法(单点更新)}$

不要想的那么复杂，因为我们这个 `update` 函数只是为了进行删除的（后面会讲），所以直接一股脑的全部赋值 `v` 就好了。

```cpp
void update(int id, int l, int r, int x, int v) {
	if(l == r) {
		maxv1[id] = {v, v}; //赋值为v 
		maxv2[id] = {v, v, v}; //赋值为v 
		return ;
	}
	int mid = (l + r) >> 1;
	//找到需要更新的点在哪个区间
	if(x <= mid) update(id * 2, l, mid, x, v); //如果需要更新的点在左边 
	else update(id * 2 + 1, mid + 1, r, x, v); //如果需要更新的点在右边 
	pushup(id); //最后进行区间更新 
}
```

$\large\text{query1 函数的写法}$

在先这里说明一下，`query` 函数是有两个的：一个是查找不带距离的，一个是查找带距离的。所以需要写成 `query1`。

每次找到一个新的区间最大值 `t`，如果 `t.sum > ans.sum`，则更新：$ans=t$，之后返回回去。

```cpp
node1 query1(int id, int l, int r, int x, int y) {
	if(x <= l && r <= y) return maxv1[id]; //找到所属区间了,返回回去 
	int mid = (l + r) >> 1;
	node1 ans = {0, 0}; //记录答案
	//区间查找和单点更新不同,因为区间查找设计到了很多值,需要分段查找 
	if(x <= mid) ans = query1(id * 2, l, mid, x, y); //刚开始是不需要比较max的,因为ans刚开始赋值为{0,0} 
	if(y > mid) {
		node1 t = query1(id * 2 + 1, mid + 1, r, x, y); //这里就需要记录答案了 
		ans = ans.sum > t.sum ? ans : t; //比较最大值 
	}
	pushup(id); //似乎可以不用写,但我还是莫名其妙的写了 
	return ans; //返回 
}
```

$\large\text{query2 函数的写法}$

其实也没多难，只不过是加上了距离而已。

每次找到一个新的区间最大值 `t`，如果 `t.sum + t.maxs * 2 > ans.sum + ans.maxs * 2`，则更新：$ans=t$，之后返回回去。

```cpp
node2 query2(int id, int l, int r, int x, int y) {
	if(x <= l && r <= y) return maxv2[id]; //找到所属区间了,返回回去 
	int mid = (l + r) >> 1;
	node2 ans = {0, 0, 0}; //记录答案
	//区间查找和单点更新不同,因为区间查找设计到了很多值,需要分段查找 
	if(x <= mid) ans = query2(id * 2, l, mid, x, y); //刚开始是不需要比较max的,因为ans刚开始赋值为{0,0,0} 
	if(y > mid) {
		node2 t = query2(id * 2 + 1, mid + 1, r, x, y); //这里就需要记录答案了 
		ans = (ans.sum + ans.maxs * 2 > t.sum + t.maxs * 2 ? ans : t); //比较最大值 
	}
	pushup(id); //似乎可以不用写,但我还是莫名其妙的写了
	return ans; //返回 
}
```

$\Large\text{主函数的写法}$

1. 用快读输入 $n、a、s$。

```cpp
n = read();
for (int i = 1; i <= n; i++) S[i] = read();
for (int i = 1; i <= n; i++) A[i] = read();
```

2. 开始建树

```cpp
build(1, 1, n);
```

3. 算出第一次的答案，并且输出答案，并且删除这个点

```cpp
for (int i = 1; i <= n; i++) if(S[i] * 2 + A[i] > sum + maxs * 2) sum = A[i], maxs = S[i], pos = i; //找出最大值 
write(sum + maxs * 2); //输出 
putchar('\n');
update(1, 1, n, pos, 0); //重点来了：这里是删除操作，因为我们不可能在线段树上做到真的删除，因此赋值为0，当作没出现过 
```

4. 求出 $1\sim pos-1$ 的最大疲劳值和 $pos+1\sim n$ 的最大疲劳值。

```cpp
node1 t1 = {0, 0}; node2 t2 = {0, 0, 0};
if(pos - 1 >= 1) t1 = query1(1, 1, n, 1, pos - 1); //注意不能越界 
if(pos + 1 <= n) t2 = query2(1, 1, n, pos + 1, n); //注意不能越界
```

5. 找出最大疲劳度，更新各项的值，输出答案，删除节点

```cpp
sum += (t2.sum + t2.maxs * 2 > t1.sum + maxs * 2 ? t2.sum : t1.sum); //记住，sum永远代表着推销用户的疲劳度 
pos = (t2.sum + t2.maxs * 2 > t1.sum + maxs * 2 ? t2.pos : pos); //如果pos+1~n的区间疲劳值更大，则更新pos，否则不更新 
int now_pos = (t2.sum + t2.maxs * 2 > t1.sum + maxs * 2 ? t2.pos : t1.pos); //记录待会会删除的节点(谁的疲劳值的就删除谁) 
t2.sum + t2.maxs * 2 > t1.sum + maxs * 2 ? write(sum + t2.maxs * 2) : write(sum + maxs * 2); //输出疲劳值 
maxs = (t2.sum + t2.maxs * 2 > t1.sum + maxs * 2 ? t2.maxs : maxs); //注意：不要在上面就更新maxs，因为我们的t1需要用到maxs，如果提前更新，有可能造成答案错误 
putchar('\n');
update(1, 1, n, now_pos, 0); //删除节点 
```

	return ans; //返回

	for (int i = 1; i <= n; i++) A[i] = read();
	build(1, 1, n);
	for (int i = 1; i <= n; i++) if(S[i] * 2 + A[i] > sum + maxs * 2) sum = A[i], maxs = S[i], pos = i; //找出最大值

		t2.sum + t2.maxs * 2 > t1.sum + maxs * 2 ? write(sum + t2.maxs * 2) : write(sum + maxs * 2); //输出疲劳值

		putchar('\n');
		update(1, 1, n, now_pos, 0); //删除节点 
	}
    return 0;
}

## [第三题](https://www.luogu.com.cn/problem/P2058)

### 题目大意

给定 $n$ 艘船，每艘船来的时间为 $t_i$ 秒，有 $k_i$ 个人，每个人来自不同的国家。对于每一艘船的到来，请记录在 $24$ 小时内（$86400$ 秒），乘船来的人中有多少不同国家。

### 题目思路

利用队列的特征，把每一个到港口的人全部都放入队列末端，之后查询的时候，就删除队头元素。知道队头元素到达港口的时间 $+86400>$ 现在这艘船到达港口的时间，就停止删除。

至于记录答案，可以开一个 $cnt$ 数组，$cnt_i$ 表示第 $i$ 种国家的人数，在加入新元素的时候，如果 $cnt_i = 0(\text{表示还没有这种国家的人})$，这时候正好进来了一个 $i$ 类国家的人，则 $cnt_i+1,ans+1$。同理，在删除的时候，如果 $cnt_i=1(\text{这种国家的人只剩下一个了})$，这时候正好这种人到达港口的时间 $+86400>$ 现在这艘船到达港口的时间，则 $cnt_i-1,ans-1$。

上代码：

```cpp
#include <bits/stdc++.h>
#define int long long //好习惯 
#define maxn 100010 
using namespace std;

int read() {
	int x = 0, f = 1;
	char ch = getchar();
	while(ch < '0' || ch > '9') f *= (ch == '-' ? -1 : 1), ch = getchar();
	while(ch >= 48 && ch <= 57) x = (x << 1) + (x << 3) + (ch ^ 48), ch = getchar();
	return x * f;
}

void write(int x) {
	if(x < 0) putchar('-'), x = -x;
	if(x > 9) write(x / 10);
	putchar(x % 10 ^ 48);
}

int n, siz, cnt[maxn];
struct node {
	int time, val; //分别表示达到港口的时间和来自的国家 
};

queue<node>q;
signed main() {
	n = read();
	while(n--) {
		int time = read(), k = read();
		while(k--) { //一个一个的加入 
			int t = read();
			q.push({time, t}); //把这种人加入队列 
			if(cnt[t] == 0) siz++; //如果没有这种国家的人，则siz++ 
			cnt[t]++; //这种国家的人口数量++ 
		}
		while(!q.empty() && q.front().time + 86400 <= time) { //如果队列里的元素没空，且到达港口时间超限(TLE) 
			if(cnt[q.front().val] == 1) siz--; //如果这种国家的人口的数量只剩下一个了，则siz-- 
			cnt[q.front().val]--; //这种国家的人口数量-- 
			q.pop(); //去掉这种人 
		}
		write(siz);
		putchar('\n');
	}
	return 0;
}
```

## [第四题](https://www.luogu.com.cn/problem/P2119)

### 题目大意

给定 $m$ 种材料，选出其中四种材料，按照题目描述构建成一个魔法阵，魔法阵中的材料分别称：$A$ 物品、$B$ 物品、$C$ 物品和 $D$ 物品。求每种材料作为一个魔法阵中的四种物品的次数是多少。

### 题目思路

先打出暴力，分别枚举四种物品，时间复杂度 $O(m^4)$（能拿 $50$ 分）。

			ans[c][3] += sum * cnt[d];
			ans[d][4] += sum * cnt[c];

		write(ans[x[i]][2]), putchar(' ');

## [第三题](https://www.luogu.com.cn/problem/P3956)

### 题目大意

给你一个棋盘，有一些格子被染成了两种颜色。你可以从一个有颜色的格子走向另一个有颜色的格子，若两个格子颜色相同，则不付出代价，否则付出 $1$ 点代价。

另外， 你可以花费 $2$ 个金币施展魔法让下一个无色格子暂时变为你指定的颜色。但**这个魔法不能连续使用**， 而且这个魔法的持续时间很短，也就是说，如果你使用了这个魔法，走到了这个暂时有颜色的格子上，你就不能继续使用魔法； 只有当你离开这个位置，走到一个本来就有颜色的格子上的时候，你才能继续使用这个魔法，而当你离开了这个位置（施展魔法使得变为有颜色的格子）时，这个格子恢复为无色。

### 题目思路

考虑 `DFS`，每次向四周枚举位置，设当前位置为 $(x,y)$，走到当前位置需要花费的金币数为 $sum$，还需要记录有没有连续使用过魔法 $is$，新枚举的点位置为 $(tx,ty)$，可以进行以下几种情况的判断：

1. 如果 $(tx,ty)$ 的范围超出地图边界，或者已经访问过了，则不枚举这个点。
2. 如果 $(tx,ty)$ 的颜色 $=$ $(x,y)$ 的颜色，则需要在这个点上面花 $sum$ 个金币。
3. 如果 $(tx,ty)$ 的颜色 $=$ $(x,y)$ 的颜色，且 $(tx,ty)$ 的颜色 $\ne$ 白色，则需要在这个点上面花 $sum+1$ 个金币。
4. 如果 $(tx,ty)$ 的颜色 $=$ 白色，且 $is=0\ \text{(即没有连续使用过魔法)}$，则需要在这个点上面花 $sum+2$ 个金币（花费魔法之后的 $(tx,ty)$ 要与 $(x,y)$ 的颜色需要相同）。

由于 `DFS` 时间复杂度很高，所以使用记忆化搜索，设 `f[x][y]` 为走到这个点需要的最小金币数，如果 $sum \ge$ `f[x][y]`，则不枚举；否则更新。

```cpp
#include <bits/stdc++.h>
#define maxn 110
#define inf 0x3f3f3f3f
using namespace std;

int n, m, a[maxn][maxn], f[maxn][maxn];
int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};
int vis[maxn][maxn];
struct node {
	int x, y, now, pts, is;
};

void dfs(int x, int y, int sum, bool is) {
	if(sum >= f[x][y]) return; //记忆化搜索 
	f[x][y] = sum; //更新
	if(x == n && y == n) return; //走到终点了，回去 
	for (int i = 0; i < 4; i++) {
		int tx = x + dx[i], ty = y + dy[i];
		if (tx >= 1 && tx <= n && ty >= 1 && ty <= n && !vis[tx][ty]) { //不能越界，且没有标记过 
			if(a[x][y] == a[tx][ty]) vis[tx][ty] = 1, dfs(tx, ty, sum, 0); //如果两个格子的颜色相同
			else if(a[x][y] != a[tx][ty] && a[tx][ty] != 0) vis[tx][ty] = 1, dfs(tx, ty, sum + 1, 0); //如果两个格子的颜色不同
			else if(a[tx][ty] == 0 && is == 0) vis[tx][ty] = 1, a[tx][ty] = a[x][y], dfs(tx, ty, sum + 2, 1), a[tx][ty] = 0; //如果新格子的颜色为白色，且没有连续使用魔法 
			vis[tx][ty] = 0; //回溯 
		}
	}
}

signed main() {
	memset(f, 0x3f, sizeof(f));
	scanf("%d%d", &n, &m);
	for (int i = 1; i <= m; i++) {
		int x, y, color;
		scanf("%d%d%d", &x, &y, &color);
		a[x][y] = color + 1;
	}
	vis[1][1] = 1; //起始点进行标记 
	dfs(1, 1, 0, 0);
	if(f[n][n] < inf) printf("%d\n", f[n][n]);
	else puts("-1"); //没有答案的情况 
	return 0;
}
```

## [第四题](https://www.luogu.com.cn/problem/P3957)

### 题目大意

- 直线的正方向上有 $n$ 个点，他们到原点的距离为 $x_i$，第 $i$ 个点有一个权值 $s_i$。**权值可能为负**。
- 从原点开始向右跳。假设原点为第 $0$ 个点，每次能跳到 $[s_i+d−g,s_i+d+g]$ 中**在第 $i$ 个点右边**的任意一个点，并获得对应的权值。
- 给定 $d,k$ 现在想要在获得的权值之和大于等于 $k$ 的前提下，最小化 $g$。
- $1\le n\le 500000,1\le d\le 2000,1\le x_i,k\le 10^9,∣s_i∣\le 10^5$。

### 题目思路

貌似与[这道题](https://www.luogu.com.cn/problem/P2678)差不多，都需要用到二分答案，不过在 `check` 函数上有改变。

----

先说如何二分答案。二分左边界很好想，就是不用金币，即为 $0$。而右边界设成最大值 $10^9$ 就好了。

而`check`函数怎么写呢？我们如果使用贪心会错，因此使用`DP`：

1. 状态：定义一个一维数组 `f`，`f[i]` 表示从第 $i$ 个格子向右跳能获得的最大分值。
2. 状态转移方程：考虑从后往前推，我们的`f[i]` 需要跳到后面的某个`f[j]`，而到底需要跳到哪个`f[j]`呢？ 这里就可以直接暴力枚举了（其实是我不会单调队列优化），还需要注意 $j$ 的距离是要求在范围之内的，因此可得 `f[i] = max(f[j] + a[i].s)`
3. 初始化：可以不与后面的进行连接，`f[i] = a[i].s`
4. 答案：由于我们要求从起点 $0$ 出发之后的最大分值，所以答案为 `f[0]`。

如果答案的分值 $\ge k$，则说明成功了，记录答案，去找更小的答案；否则只能去找更大的答案。

上代码：

```cpp
#include <bits/stdc++.h>
#define maxn 500010
#define int long long //不开long long见祖宗
using namespace std;

int n, d, k, f[maxn];
struct node {
	int x, s;
}a[maxn];

bool check(int x) {
	for (int i = n; i >= 0; i--) { //注意要枚举到0
		f[i] = a[i].s; //初始化
		for (int j = i + 1; a[j].x - a[i].x <= d + x && j <= n; j++) //不能越界
			if(a[j].x - a[i].x >= d - x && f[j] + a[i].s > f[i]) f[i] = f[j] + a[i].s; //如果能更新则更新
	}
	return f[0] >= k; //答案如果满足条件
}

signed main() {
	scanf("%lld%lld%lld", &n, &d, &k);
	for (int i = 1; i <= n; i++)
		scanf("%lld%lld", &a[i].x, &a[i].s);
	int l = 0, r = 1000000000, ans = 1000000000; //初始化
	while(l <= r) {
		int mid = (l + r) >> 1;
		if(check(mid)) ans = mid, r = mid - 1; //找到答案，记录答案，缩小r
		else l = mid + 1; //否则放大l
	}
	if(ans != 1000000000) printf("%lld\n", ans); //如果找到了答案，则输出答案
	else puts("-1"); //否则输出-1
	return 0;
}
```

可惜只能拿 $50$ 分...

----

那么如何优化呢？`check`函数的部分肯定是不能再优化了（都说了不会单调队列优化），所以只能在二分上下手了。

有人表示二分有啥好下手呢？$\log_2 (5\times10^{10})$ 最多就为 $35$，进行优化也就是个常数级别的优化，有啥用。

其实有的时候常数是能决定很多事情的，就比如这道题。我们其实可以考虑缩短二分边界进行常熟优化。

但左边界是不可能改动的了（毕竟有的时候不需要花费金币），所以只能在右边界上进行改动了。

观察样例，我们可以发现，我们其实可以只选出分值为正整数的数，求出这些数中相隔最远的**距离值**，就作为我们的右边界。举个例子：

```cpp
2 6
5 -3
10 3
11 -3
13 1
17 6
20 2
```

其中分值为正整数的有：

```cpp
2 6
10 3
13 1
17 6
20 2
```

那么其中相隔最远的**距离值**为 $10-2=8$，所以二分边界为 $8$，根本不需要什么 $10^9$。

还需要注意一个点，如果其中所有为正整数的**分值**的和 $<k$，则输出 $-1$（虽说此题根本没有 $-1$ 这种情况）。

上代码：

```cpp
#include <bits/stdc++.h>
#define maxn 500010
#define int long long //不开long long见祖宗 
using namespace std;

int n, d, k, sum, f[maxn];
int l = 0, r, ans = 1000000000;
struct node {
	int x, s;
}a[maxn];

bool check(int x) {
	for (int i = n; i >= 0; i--) { //注意要枚举到0
		f[i] = a[i].s; //初始化
		for (int j = i + 1; a[j].x - a[i].x <= d + x && j <= n; j++) //不能越界
			if(a[j].x - a[i].x >= d - x && f[j] + a[i].s > f[i]) f[i] = f[j] + a[i].s; //如果能更新则更新
	}
	return f[0] >= k; //答案如果满足条件
}

signed main() {
	scanf("%lld%lld%lld", &n, &d, &k);
	for (int i = 1, last = 0; i <= n; i++) {
		scanf("%lld%lld", &a[i].x, &a[i].s);
		if(a[i].s > 0) sum += a[i].s, r = max(a[i].x - last, r), last = a[i].x; //记录两个正整数分值之间的距离值的距离（伦敦大雾），取其中最大的 
	}
	if(sum < k) { //如果所有正整数的分值的和<k，说明没有方法 
		puts("-1");
		return 0;
	}
	while(l <= r) {
		int mid = (l + r) >> 1;
		if(check(mid)) ans = mid, r = mid - 1; //找到答案，记录答案，缩小r
		else l = mid + 1; //否则放大l
	}
	printf("%lld\n", ans);
	return 0;
}
```

## [第二题](https://www.luogu.com.cn/problem/P5016)

### 题目大意

给出 $n$ 个数，再给出一个 $m$ 位置，定义 $a$ 和 $b$,（$m$ 不属于 $a$ 或 $b$）： $a$ 为 $1\sim m−1$ 个数每个数用这个数到 $m$ 的距离乘这个数的积之和，$b$ 则为 $m+1\sim n$ 中再在这 $n$ 个每个数用这个数到 $m$ 的距离乘这个数的积之和，然后在其中一个位置 $(p_1)$ 加入了一个数 $s_1$，现在再给你一个数 $s_2$，求这个数加在哪一个位置能让 $a$ 和 $b$ 的差最小（加上去这个数的计算方法和之前相同）。

### 题目思路

笑点分析：由于这道题太简单了，所以我都没在洛谷上提交，直接去了 $\color{green}\text{acwing}$ 上提交。

首先想出暴力，枚举 $s_2$ 可以放置的军营，时间复杂度为 $O(n^2)$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, m, p1, s1, s2, ans_cha = 1000000000, ans_i, a[maxn];
int work(int x) {
    int sum1 = 0, sum2 = 0;
    a[x] += s2;
    for (int i = 1; i < m; i++) sum1 += abs(m - i) * a[i];
    for (int i = m + 1; i <= n; i++) sum2 += abs(m - i) * a[i];
    a[x] -= s2;
    return abs(sum1 - sum2);
}

int main() {
	cin >> n;
	for (int i = 1; i <= n; i++) cin >> a[i];
	cin >> m >> p1 >> s1 >> s2;
	a[p1] += s1;
	for (int i = 1; i <= n; i++) {
        int x = work(i);
		if(x < ans_cha) {
			ans_cha = x;
			ans_i = i;
		}
	}
	cout << ans_i << endl;
	return 0;
}
```

超时之后，我们接着来观察题目，能否进行优化。

我们可以发现：每次枚举的时候都要把整个序列遍历一遍，而有些值是会被我们重复计算的，所以我们可以把这些重复计算的值记录下来。

令每次枚举到的下标为 $i$，$1\sim m-1\ \text{所有数的和}\ =sum1$，$m+1\sim n\ \text{所有数的和}\ =sum2$。如果 $i<m$，则龙士气 $=sum1+|m-i|\times a_i$，虎士气为 $sum2$；如果 $i>m$，则龙士气 $=sum1$，虎士气为 $sum2+|m-i|\times a_i$。

这样就可以省去大量重复操作，时间复杂度为 $O(n)$。

不过需要注意 $i=m$ 的情况也要算上，即哪个势气都不加上（我就被卡过）。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define int long long //不开long long见祖宗 
using namespace std;

int n, m, p1, s1, s2, sum1, sum2, ans_cha = 1000000000, ans_i, a[maxn]; 
signed main() {
	scanf("%lld", &n);
	for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);
	scanf("%lld%lld%lld%lld", &m, &p1, &s1, &s2);
	a[p1] += s1; //加上s1个兵 
	for (int i = 1; i < m; i++) sum1 += abs(m - i) * a[i]; //龙势力 
	for (int i = m + 1; i <= n; i++) sum2 += abs(m - i) * a[i]; //虎势力 
	for (int i = 1; i <= n; i++) {
		if(i == m && abs(sum1 - sum2) < ans_cha) { //i=m的情况
			ans_cha = abs(sum1 - sum2);
			ans_i = i;
		}
		if(i < m && abs(sum1 + abs(m - i) * s2 - sum2) < ans_cha) { //i < m的情况
			ans_cha = abs(sum1 + abs(m - i) * s2 - sum2);
			ans_i = i;
		}
		if(i > m && abs(sum2 + abs(m - i) * s2 - sum1) < ans_cha) { //i > m的情况
			ans_cha = abs(sum2 + abs(m - i) * s2 - sum1);
			ans_i = i;
		}
	}
	printf("%lld\n", ans_i); //输出 
	return 0;
}
```

## [第三题](https://www.luogu.com.cn/problem/P5017)

### 题目大意

有 $n$ 名同学要乘坐摆渡车从 $A$ 到 $B$，第 $i$ 位同学在第 $t_i$ 分钟去等车。有一辆摆渡车，容量无限大，从 $𝐴$ 出发、 把车上的同学送到 $B$、再回到 $A$（去接其他同学），往返一趟总共花费 $m$ 分钟（上下车时间忽略不计）。要将所有同学都送到 $B$ 已知你可以任意安排摆渡车出发的时间，求所有人等车时间之和的最小值。摆渡车回到 $A$ 后可以即刻出发。

$n≤500,m≤100,t_i≤4e6$。

### 题目思路

很明显，这是一道`DP`的题，所以考虑动态规划：

1. 状态：定义一个一维数组`f`，`f[i]`表示末班车发车时刻为 $i$ 时，等车时间之和的最小值.
2. 初始化：

> 先确定 $i$ 的范围，观察样例，假设 $m=5$，那么当倒数第二个人在第 $12$ 分钟走后，最后一个人在第 $13$ 分钟到，要等到第 $17$ 分钟才能走，所以 $0≤i≤max(a_i)+m-1$。
>
> 遍历所有 $a_j$，如果 $a_j≤i$，则 $f_i=f_i+(i-a_j)$；否则不动。
>
> 但是太慢了，所以进行合并同类项，$f_i=cnt_i\times i-sum_i\ (cnt_i\ \text{表示在前}\ i\ \text{分钟到达车站的人数},sum_i\ \text{则表示}\ \text{在前}\ i\ \text{分钟到达车站的人的等待时间总和})$。

3. 状态转移方程：`f[i] = min(f[i], f[j] + 末班车上所有人的等待时间和)`$(0≤i≤max(a_i)+m-1)$。

> 和初始化一样，还是太慢了，而末班车上所有人的等待时间和 $=(cnt_i-cnt_j)\times i-(sum_i-sum_j)$。
>
> 而 $j$ 的范围怎么确定呢？由于两班车之间的发车时间差最少得是 $m$，所以 $j≤i-m$；同理，两班车之间的发车时间差最多只能是 $2m-1(\text{如果达到}\ 2m\ \text{，说明中间有两辆车，明明有两辆车，那就不能只考虑一辆车的情况了})$

4. 答案：`min(f[i])`（$x≤i≤x+m-1$）

```
#include <bits/stdc++.h>
#define maxn 510
#define N 4000110 //时间最大值，注意是t+m-1 
#define inf INT_MAX //最大值 
using namespace std;

int n, m, maxa, ans = inf, a[maxn], f[N], cnt[N], sum[N]; //f[i]表示末班车发车时刻为i时，等车时间之和的最小值 
signed main() {
	scanf("%d%d", &n, &m); 
	for (int i = 1; i <= n; i++) {
		scanf("%d", &a[i]);
		cnt[a[i]]++, sum[a[i]] += a[i], maxa = max(maxa, a[i]); //取出a[i]的最大值 
	}
	for (int i = 1; i <= maxa + m - 1; i++) //不能从0开始 
		cnt[i] += cnt[i - 1], sum[i] += sum[i - 1]; //计算前缀和 
	for (int i = 0; i <= maxa + m - 1; i++) { //遍历所有时间 
		if(i >= m && cnt[i] == cnt[i - m]) { //剪枝，如果过了m分钟之后没有人到达，则等待时间则为m分钟之前的等待时间，因为没来人 
			f[i] = f[i - m];
			continue;
		}
		f[i] = cnt[i] * i - sum[i]; //初始化
		for (int j = max(0, i - 2 * m + 1); j + m <= i; j++) //j的范围
			f[i] = min(f[i], f[j] + (cnt[i] - cnt[j]) * i - (sum[i] - sum[j])); //找出最小值 
	}
	for (int i = maxa; i <= maxa + m - 1; i++) ans = min(f[i], ans); //找答案，注意是从maxa开始 
	printf("%d\n", ans);
	return 0;
}
```

## [第四题](https://www.luogu.com.cn/problem/P5018)

### 题目大意

给出一个二叉树，判断给定的树的最大对称二叉子树的节点数。

对称二叉树的定义：

1. 二叉树
2. 将这棵树所有节点的左右子树交换，新树和原树对应位置的结构相同且点权相等

### 题目思路

~~哎不是为啥 T4 这么简单？比 T3 简单多了~~

枚举每棵子树，判断递归的判断左右子树分别相等。相等就记数，更新答案即可（是的，只有一行分析）。

```cpp
#include <bits/stdc++.h>
#define maxn 1000010
using namespace std;

inline int read() { //快读 
	int x = 0, f = 1;
	char ch = getchar();
	while(ch < '0' || ch > '9') f *= (ch == '-' ? -1 : 1), ch = getchar();
	while(ch >= 48 && ch <= 57) x = (x << 1) + (x << 3) + (ch ^ 48), ch = getchar();
	return x * f;
}

inline void write(int x) { //快写 
	if(x > 9) write(x / 10);
	putchar(x % 10 ^ 48);
}

int n, ans, siz[maxn]; //siz[i]表示下标为i的子树的大小 
struct node {
	int val, left, right;
}a[maxn]; //记录一个节点的权值，左右子树的下标 

inline bool work(int l, int r) {
	if(l == -1 && r == -1) return 1; //如果都搜到了空节点，则返回true 
	if(l == -1 || r == -1) return 0; //如果有一个搜到了空节点，则返回false 
	if(a[l].val != a[r].val) return 0; //如果权值不相等，则返回false
	return work(a[l].left, a[r].right) && work(a[l].right, a[r].left); //递归判断左右子树是否相等 
}

inline int dfs(int x) { //用来计算子树大小 
	return x == -1 ? 0 : siz[x] = dfs(a[x].left) + dfs(a[x].right) + 1; //如果搜到空节点，则大小为0；否则接着往下搜 
}

signed main() {
	n = read();
	for (int i = 1; i <= n; i++) a[i].val = read();
	for (int i = 1; i <= n; i++) a[i].left = read(), a[i].right = read();
	dfs(1); //先预处理 
	for (int i = 1; i <= n; i++) if(work(i, i)) ans = ans > siz[i] ? ans : siz[i]; //如果发现可以更新，则更新 
	write(ans);
	return 0;
}
```

## [第二题](https://www.luogu.com.cn/problem/P5661)

### 题目大意

一种地铁换乘公交车的优惠方案：
1. 在搭乘一次地铁后可以获得一张优惠票，有效期为 $45$ 分钟，在有效期内可以消耗这张优惠票，免费搭乘一次票价不超过地铁票价的公交车。在有效期内指开始乘公交车的时间与开始乘地铁的时间之差小于等于 $45$ 分钟，即：
    $t_{bus}−t_{subway}≤45$
2. 搭乘地铁获得的优惠票可以累积，即可以连续搭乘若干次地铁后再连续使用优惠票搭乘公交车。
3. 搭乘公交车时，如果可以使用优惠票一定会使用优惠票；如果有多张优惠票满足条件，则优先消耗获得最早的优惠票。

### 题目思路

每次都把地铁票记录下来，之后后面碰到公交车时再往前面找地铁票，找到之后删除这张地铁票（时间复杂度 $O(n^2)$）。

上代码（$80$ 分做法）：

```
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, ans, t = 0;
struct node {
	int t, val;
}q[maxn]; //记录每一张地铁票

int main() {
	cin >> n;
	while(n--) {
		int d, time, val;
		cin >> d >> val >> time;
		if(d == 0) {
			ans += val; //加上需要花的钱数
			q[++t] = {time, val}; //把这张地铁票记录下来
		} else {
			bool is = 0; //判断是否可以不花钱
			for (int i = 1; i <= t; i++)
				if(q[i].val >= val && q[i].t + 45 >= time) { //要求时间不能越界，且钱数也不能越界
					for (int j = i + 1; j <= t; j++)
						q[j - 1] = q[j]; //删除这张地铁票
					t--; //地铁票总是-1
					is = 1;
					break;
				}
			if(!is) ans += val; //老老实实买公交车票
		}
	}
	cout << ans << endl;
	return 0;
}
```

## [第三题](https://www.luogu.com.cn/problem/P5662)

### 题目大意

给定 $T$ 天 $N$ 种纪念品每天的价格。可以进行两种操作：

1. 任选一个纪念品，若手上有足够金币，以当日价格购买该纪念品
2. 卖出持有的任意一个纪念品，以当日价格换回金币

每天卖出纪念品换回的金币可以**立即**用于购买纪念品，当日购买的纪念品也可以**当日卖出**换回金币。当然，一直持有纪念品也是可以的。

要求第 $T$ 天卖出**所有**纪念品换回金币。

问现在有 $M$ 枚金币，在 $T$ 天之后最多能拿到多少金币？

### 题目思路

首先一眼看出这是一道`DP`题，但是又应该怎么写呢？

考虑完全背包，我们进行 $T-1$ 轮完全背包（因为第 $T$ 天不能再买纪念品了）。

把今天**手里的钱**当做背包的**容量**，

把商品**今天的价格**当成它的**消耗**,

把商品**明天的价格**当做它的**价值**，

每一天结束后把**总钱数加上今天赚的钱**，直接写背包模板即可。

另： 在这道题中，我们可以把商品和钱看成同样的东西，因为题目中说了：可以**当天买当天卖**，所以不必考虑跨天的买卖，**只需考虑当天**的即可，这满足动态规划对于最优化原理和无后效性的要求，可以大胆地购买。

1. 状态：定义`dp[i]`为手上有 $i$ 枚金币，能盈利的最大价值（不含成本）

2. 状态转移方程：`dp[k] = max(dp[k], dp[k - price[i][j]] + price[i + 1][j] - price[i][j])`
3. 初始化：`dp[i] = 0`（每一天都要重新初始化）
4. 答案：枚举的边界

```cpp
#include <bits/stdc++.h>
#define day 110
#define N 110
using namespace std;

int T, n, m, ans, price[day][N], dp[10010];
signed main() {
	cin >> T >> n >> m;
	ans = m; //刚开始的时候的钱数
	for (int i = 1; i <= T; i++)
		for (int j = 1; j <= n; j++)
			cin >> price[i][j];
	for (int i = 1; i < T; i++) { //从1枚举到T-1 
		memset(dp, 0, sizeof(dp)); //初始化 
		for (int j = 1; j <= n; j++) //枚举n个纪念品
			for (int k = price[i][j]; k <= ans; k++) //枚举背包边界
				dp[k] = max(dp[k], dp[k - price[i][j]] + price[i + 1][j] - price[i][j]); //状态转移方程 
		ans += dp[ans]; //加上今天的盈利
	}
	cout << ans << endl; //答案 
	return 0;
}
```

## [第四题](https://www.luogu.com.cn/problem/P5663)

### 题目大意

给定一张包含 $n$ 个点和 $m$ 条边的无向图，再给定 $q$ 个询问：$a_i,L_i$，判断是否存在一条从1号点走到 $a_i$ 号点的恰好经过 $L$ 条边的路径。

### 题目思路

我们可以尝试的找一下规律，例如下图：

![](https://cdn.luogu.com.cn/upload/image_hosting/tfom5z2s.png)

如果要 $3$ 点要生产 $2$ 等级的材料，那么可以通过上边的那条路线来传递到 $1$ 点（路线长度为 $2$），但是如果要生产 $3$ 等级的材料，则不能走上面那条路。

如果要 $3$ 点要产生 $3$ 等级的材料，那么可以通过下边的那条路线来传递到 $1$ 点（路线长度为 $3$），但是如果要生产 $4$ 等级的材料，则不能走下面那条路。

我们可以发现一个性质，设 $u$ 点到 $v$ 点的距离为 $w$，那么 $L-w$ 得为偶数才能让 $1$ 点生产原材料，换句话说，$L$ 和 $w$ 同奇偶。

但我们还需要注意一点，举个例子，例如 $3$ 点要生产 $1$ 等级的材料，那么需要让 $1$ 点生产原材料吗？很明显不需要，因为根本够不着。

所以我们能得出一个性质：$L$ 和 $w$ 同奇偶，且 $w\le L$。

到这里，看似问题已经解决了，实际还没有，因为我们并不知道 $w$ 是多少，我们得求出 $w$ 是多少。

因此，我们需要分成两部分，分别求 $w$ 为偶数时的最短路和 $w$ 为奇数时的最短路。

拿为什么要求的是最短路呢。因为这里要求 $w\le L$，考虑贪心的性质，$w$ 越短越好，因此选择最短路。

设`dis[i][0]`为从 $1$ 点到 $i$ 点的最短路，且最短路长度为偶数，而`dis[i][1]`为从 $1$ 点到 $i$ 点的最短路，且最短路长度为奇数。

利用`BFS`，每次遍历与 $x$ 相邻的点 $y$，并且检查是否可以更新，即

```cpp
dis[y][0] = min(dis[y][0], dis[x][1] + 1);
dis[y][1] = min(dis[y][1], dis[x][0] + 1);
```

如果`dis[y][0]`的值比原来小，或者`dis[y][1]`的值比原来小，则把 $y$ 加入队列，接着进行更新。

最后还需要注意一点，如果 $u$ 点没有连边（例如下图 $3$ 点），那么也不能让 $1$ 点生产原材料。
![](https://cdn.luogu.com.cn/upload/image_hosting/ke49u8j2.png)

```cpp
#include<bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, m, q, dis[maxn][2]; //dis[i][0/1]表示从1点到i点的最短距离，0表示距离为偶数，1表示距离为奇数 
queue<int>que;
vector<int>linker[maxn]; //邻接表 
int main() {
	memset(dis, 0x3f, sizeof(dis)); //初始化 
	cin >> n >> m >> q;
	while(m--) {
		int u, v;
		scanf("%d%d", &u, &v);
		linker[u].push_back(v), linker[v].push_back(u); //邻接表加入无向图 
	}
	dis[1][0] = 0, que.push(1); //初始化 
	while(!que.empty()) {
		int x = que.front();
		que.pop();
		for (auto y:linker[x]) { //枚举与x相连的y 
			int x1 = dis[y][0], y1 = dis[y][1]; //记录在更新之前的dis[y] 
			dis[y][0] = min(dis[y][0], dis[x][1] + 1); //更新 
			dis[y][1] = min(dis[y][1], dis[x][0] + 1); //更新 
			if(dis[y][0] < x1 || dis[y][1] < y1) que.push(y); //如果值变得更小，则加入队列 
		}
	}
	while(q--) {
		int u, v;
		scanf("%d%d", &u, &v);
		if(dis[u][0] <= v && v % 2 == 0 && linker[u].size()) printf("Yes\n"); //L为偶数的情况 
		else if(dis[u][1] <= v && v % 2 == 1 && linker[u].size()) printf("Yes\n"); //L为奇数的情况 
		else printf("No\n"); //否则输出No 
	}
	return 0;
}
```

## [第三题](https://www.luogu.com.cn/problem/P7073)

### 题目大意

给定一个逻辑表达式的后缀表达式，求解当这个逻辑表达式中某个变量的值变更后这个表达式的值。

### 题目思路

如果每询问一次就重新计算一遍，那么时间复杂度为 $O(qn)$。

我们仔细想想，是不是有一些重复的计算呢？

题目里有个信息是“每个变量在表达式中出现恰好一次”，而每个询问只改变一个变量的值，这对原答案来说就产生两个可能：变或不变。这听起来是一句废话，其实蕴含的意思是：有些变量对整个表达式其决定作用，其改变则原答案也改变；有些变量对整个表达式根本没用，其变不变原答案都不变。

说明白一点，就是`1 & x = x` ，`0 | x= x` ，这两个公式里的 $x$ 就起了决定性作用，而 `0 & x = 0` ，`1 | x= 1` 的 $x$ 就是一个废物。

那我们就给树上每个结点建一个废物标记，对`&` 来说，如果一棵子树是 00，那另外一棵子树内所有叶结点都应该打上废物标记，对`|`同理。

先计算出原表示答案`ans`，这样我们在查询的时候，没被标记的就说明它往上到根节点都不存在一种让它变成废物的运算，所以答案是`!ans`，如果有标记则答案依旧为`ans`。

而对于非运算，可以直接使用德·摩根定律，这样问题就解决，时间复杂度为 $O(q+n)$。

```cpp
#include <bits/stdc++.h>
#define maxn 100010
using namespace std;

int n, q, fw[maxn * 2], a[maxn * 2], fan[maxn * 2];
string s;
stack<int>st; //栈用来建树
struct NODE {
	int l, r;
}node[maxn * 2];

int dfs(int x, int y) { //y表示x是否要取反
	a[x] ^= y; //取反，因为德·摩根定律
	if(x <= n) return a[x]; //叶节点，直接返回
	int l = dfs(node[x].l, fan[node[x].l] ^ y); //往下查找，注意要^y(德·摩根定律) 
	int r = dfs(node[x].r, fan[node[x].r] ^ y); //往下查找，注意要^y(德·摩根定律) 
	if(a[x] == 2) { //如果为&
		if(!l) fw[node[x].r] = 1; //废物标记 
		if(!r) fw[node[x].l] = 1;
		return l & r; //返回 
	}
	if(a[x] == 3) { //如果为|
		if(l) fw[node[x].r] = 1; //废物标记 
		if(r) fw[node[x].l] = 1;
		return l | r; //返回
	}
}

void dfs1(int x) { //每一个儿子都要进行废物标记
	if(x <= n) return;
	fw[node[x].l] |= fw[x], fw[node[x].r] |= fw[x]; //如果x是废物，则x的子孙后代都是废物 
	dfs1(node[x].l), dfs1(node[x].r); //接着往下进行废物标记 
}

int main() {
	getline(cin, s);
	scanf("%d", &n);
	for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
	int sum = n, len = s.size(); //sum从n开始 
	for (int i = 0; i < len; i++) {
		if(s[i] == 'x') {
			int x = 0;
			while(s[++i] != ' ') x = x * 10 + (s[i] - '0'); //把下标输入 
			st.push(x);
		} else if(s[i] == '&') {
			int x = st.top(); st.pop();
			int y = st.top(); st.pop();
			node[++sum].l = x, node[sum].r = y; //左右子树记录下来 
			st.push(sum), a[sum] = 2; //&表示2 
		} else if(s[i] == '|') {
			int x = st.top(); st.pop();
			int y = st.top(); st.pop();
			node[++sum].l = x, node[sum].r = y; //左右子树记录下来
			st.push(sum), a[sum] = 3; //|表示3
		} else if(s[i] == '!') {
			int x = st.top();
			fan[x] = !fan[x]; //进行取反 
		}
	}
	int ans = dfs(sum, fan[sum]);
	dfs1(sum); 
	scanf("%d", &q);
	while(q--) {
		int k;
		scanf("%d", &k);
		printf("%d\n", fw[k] ? ans : !ans); //如果是废物，则输出ans，否则输出!ans 
	}
	return 0;
}
```



# $2023\text{年}$

## [第一题](https://www.luogu.com.cn/problem/P9748)

### 题目大意

有 $n$ 个苹果手机排成一排，标号 $1\sim n$。接下来每天都会拿走一些苹果手机，每次从最左边的第 $1$ 个苹果手机开始，每隔 $2$ 个拿一个苹果手机。取完后将剩下的苹果手机重新排成一排。求：

1. 多少天能拿完所有苹果手机；
2. 第 $n$ 个苹果手机是在第几天拿的。

### 题目思路

我们可以把「每隔 $2$ 个取一个苹果手机」这件事情这样理解：将苹果手机每 $3$ 个分一组，每次取这一组的第一个。

例如有 $11$ 个苹果手机：

![](https://cdn.luogu.com.cn/upload/image_hosting/yx6mrnpq.png)

标红的是这一轮拿的。如果最后剩下的不足以拼成 $3$ 个一组的，就拼成不完整的一组。

很显然，这一轮取走的苹果手机数量就是分成的组数，即 $⌈\frac{n}{3}⌉$。那么我们暴力模拟这件事，每次 $n←⌈\frac{n}{3}⌉$，看多少次操作后 $n$ 变成 $0$ 即可。这是第一问。

对于第二问，我们可以这样考虑。首先最后一个苹果手机一定是在最后一组的，那么如果想取走这个苹果手机，就相当于**这个苹果手机在最后一组的第一个**。例如有 $11$ 个和 $10$ 个苹果手机：

![](https://cdn.luogu.com.cn/upload/image_hosting/akcyfbiw.png)

可以发现，只有在**最后一组仅有 $11$ 个苹果手机时，最后一个苹果手机是这一组的第一个**。也就等价于当 $n≡1(\bmod 3)$ 时，可以在这一轮取到最后一个苹果手机。

那么我们在求第一问的暴力模拟时，判断当前的 $n$ 是否模 $3$ 为 $1$。若是，记录下来这是第几轮取苹果手机。这就是第二问的答案。

注意在第一次 $n≡1(\bmod 3)$ 时就可以取到最后一个苹果手机了。往后如果还有这样的机会就不算了。

考虑计算时间复杂度。每次将 $n$ 减去 $⌈\frac{n}{3}⌉$，也就大约是 $n←\frac{2}{3}n$。不妨将其大约看作 $n←\frac{1}{2}n$，也就是每次将 $n$ 缩小一半。因此这样计算的话时间复杂度为 $O(\log_2n)$。实际运行时会偏高。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, sum, ans; //sum是需要花费的天数，ans是第几天采摘到最后一个苹果 
int main() {
	cin >> n;
	while(n) { //如果n不为0 
		sum++; //天数+1
		if(n % 3 == 1 && ans == 0) ans = sum; //如果可以采摘到最后一个苹果并且以前没有采摘过，则记录 
		n -= (n + 2) / 3; //这里需要向上取整 
	}
	cout << sum << " " << ans << endl; 
	return 0;
}
```

## [第二题](https://www.luogu.com.cn/problem/P9749)

### 题目大意

给定 $n$ 个站点、每个站点到下一个站点的距离、每个站点的加油站的价格，求从 $1$ 站点到 $n$ 站点需要花多少钱。

### 题目思路

反悔贪心思想。

从左到右考虑，如果行驶到某个加油站，缺油的时候，从之前经过的**最便宜的加油站加油**。

维护一个变量 $now$。

如果 $now\ge0$，表示现在车中的油还能走多远。

如果 $now<0$，表示当前需要加油，需要加的油量为 $⌈\frac{-now}{d}⌉$

注意本题的数据范围大，需要开 `long long`！

```cpp
#include <bits/stdc++.h>
#define maxn 100010
#define int long long
using namespace std;

int n, d, now, money = 1e9, ans, S[maxn], a[maxn]; //now表示车厢中的油还能走多远、money表示过去最低的油价、ans表示答案 
signed main() {
	cin >> n >> d;
	for (int i = 1; i < n; i++) cin >> S[i]; //每一个点到下一个点的距离 
	for (int i = 1; i <= n; i++) cin >> a[i]; //每一个点的加油站的油价 
	for (int i = 1; i <= n; i++) {
		now -= S[i]; //往前走
		money = min(money, a[i]); //记录最低油价 
		if(now < 0) { //需要加油了
			int t = -now;
			ans += (t + d - 1) / d * money; //需要花的钱 
			now += (t + d - 1) / d * d; //加完油之后还能走多远 
		}
	}
	cout << ans << endl;
	return 0;
}
```

## [第三题](https://www.luogu.com.cn/problem/P9750)

### 题目大意

给定一个一元二次方程 $ax^2+bx+c$，给出 $a、b、c$，求出这个方程最大的解。若无解，输出`NO`。

### 题目思路

也就是表示出 $\frac{-b+\sqrt {b^2-4ac}}{2a}$，我们把 $b^2-4ac$ 记为 $Δ$

若 $Δ<0$，则无解。

因为 $Δ \ge 0$，所以 $Δ \ge 0$ 较大的解是 $\frac{-b+\sqrt Δ}{2a}$。

我们把 $\sqrt Δ$ 变成 $a\sqrt b$ 的形式后。如果 $b=0,1$ 说明解是有理数，如果是有理数记得把 $-b+\sqrtΔ$ 当做整体然后除以 $2a$ 最后当做有理数输出。

注意：如果 $\sqrt Δ$ 不是有理数，那么 $\frac{-b+\sqrt Δ}{2a}$ 应该表示为 $\frac{-b}{2a} + \frac{\sqrt Δ}{2a}$

然后分个体约分，对于有理数直接约分，无理数只约掉 $a\sqrt b$ 中的 $a$ 与分母的公因数。

注意：分母永远是正数。

难点是模拟输出，细节比较多，没什么算法，直接写在这里不直观，放在代码注释中。

再说一些常见的错误输出：

```cpp
0+sqrt(5)
+sqrt(5)
sqrt(8)
sqrt(5)/1
1*sqrt(5)
2*sqrt(5)/4
5/-2
-5/-1
-5/2+3/2
```

上代码：

```cpp
#include <bits/stdc++.h>
using namespace std;

int T, m, a, b, c;
int gcd(int x, int y) {
	if(y == 0) return x;
	return gcd(y, x % y);
}

void solve() {
	cin >> a >> b >> c;
	if(a < 0) a = -a, b = -b, c = -c; //分母为正数 
	int d = b * b - 4 * a * c; //delta
	if(d < 0) { //无解 
		cout << "NO" << endl;
		return ;
	}
	if(d == 0) { //只有一个解
		int p = abs(gcd(-b, 2 * a)); //最大公因数取绝对值
		if(2 * a / p != 1) cout << -b / p << "/" << 2 * a / p << endl; //分母不为1 
		else cout << -b / p << endl;
		return ;
	}
	int k = 1;
	for (int i = 2; i * i <= d; i++)
		while(d % (i * i) == 0) { //提取出a*sqrt(b)中的 a 
			d /= i * i;
			k *= i;
		}
	if(d == 1) { //如果delta为1，说明是有理数 
		int t = -b + k;
		int p = abs(gcd(t, 2 * a)); //最大公因数取绝对值
		if(2 * a / p != 1) cout << t / p << "/" << 2 * a / p << endl; //分母不为1 
		else cout << t / p << endl;
		return ;
	}
	int p = abs(gcd(-b, 2 * a)); //最大公因数取绝对值
	if(2 * a / p != 1) cout << -b / p << "/" << 2 * a / p << "+"; //分母不为1 
	else if(-b / p != 0) cout << -b / p << "+";
	if(d == 1) {
		p = abs(gcd(k, 2 * a)); //最大公因数取绝对值
		if(2 * a / p != 1) cout << k / p << "/" << 2 * a / p << endl; //分母不为1
		else cout << k / p << endl;
		return ;
	}
	p = abs(gcd(k, 2 * a)); //最大公因数取绝对值
	if(k / p != 1) cout << k / p << "*"; //乘数不为1 
	if(2 * a / p != 1) cout << "sqrt(" << d << ")/" << 2 * a / p << endl; //分母不为1
	else cout << "sqrt(" << d << ")" << endl;
}

int main() {
	cin >> T >> m; 
	while(T--) solve();
	return 0;
}
```

## [第四题](https://www.luogu.com.cn/problem/P9751)

### 题目大意

给出一个有向图，当前在 $1$ 号点，初始在时间 $0$，必须在 $k$ 的倍数的时间出发，且到终点的时间也必须是 $k$ 的倍数。

每条边有一个边权 $w_i$，只有在当前时间 $\ge w_i$ 时才可以通过，且不能在原地不动，即每一个时间点必须走一条边。

问从 $1$ 号点出发到 $n$ 号时最早的时刻。（没有方案则输出 $-1$）

### 题目思路

由于这道题边权为 $1$，可以考虑用普通`bfs`来解决。

由于这道题会有重边和自环，所以考虑反向存图。

这道题会有环状，如下图：

![](https://cdn.luogu.com.cn/upload/image_hosting/ibgy25qv.png)

因此，定义一个 $vis$ 数组，$vis_{i\ j}$ 表示走到第 $i$ 个点，$\text{需要的时间}\ \%k=j$，如果 $vis_{i\ j}$ 访问过了，则进入下一轮循环。

设当前点为 $x$，找出与 $x$ 相连的所有的点，如果当前时间大于经过这条路的开放时间，则加入队列中（注意不能等于，应为我们是倒着走的）

之后我们枚举结束时间（因为反向存图，所以要从结束时间一步一步往前推），如果能从终点走回起点，$\text{并且回到起点的时间}\%k=0$，则这个点是答案。

但由于一个一个枚举太慢了，所以使用二分答案，加快速度。

代码如下：

```cpp
#include <bits/stdc++.h>
#define maxn 10010
#define int long long //十年OI一场空，不开long long见祖宗 
using namespace std;

int n, m, k;
bool vis[maxn][110]; //标记数组 
struct rake {
	int to, start_time; //存边 
};

struct path {
	int pos, time; //记录走到这个点的当前时间 
};

vector<rake>linker[maxn];
bool bfs(int stime) {
    queue<path>q;
    memset(vis, 0, sizeof(vis));
	q.push({n, stime});
	while(!q.empty()) {
		int u = q.front().pos, p = q.front().time;
		q.pop();
		if(u == 1 && p % k == 0) return true; //如果回到起点并且时间%k=0，则返回true 
		if(vis[u][p % k] || p <= 0) continue; //如果时间耗尽还是没有走回起点
		vis[u][p % k] = 1; //标记
		for (auto i:linker[u]) { //遍历u能到达的所有的点 
			int v = i.to, w = i.start_time;
			if(p > w) //这里不能等于，因为我们是倒着走的
				q.push({v, p - 1}); //由于我们是倒着走的，所以时间要-1 
		}
	}
	return false;
}

signed main() {
	cin >> n >> m >> k;
	for (int i = 1; i <= m; i++) {
		int u, v, a;
		cin >> u >> v >> a;
		linker[v].push_back({u, a});
	}
	int l = 0, r = 5000000, ans = -1; //二分答案 
	while(l <= r) {
	    int mid = (l + r) / 2;
	    if(bfs(mid * k)) ans = mid * k, r = mid - 1; //记录答案，并且继续寻找最优解 
	    else l = mid + 1; //否则缩短区间 
	}
	cout << ans << endl;
	return 0;
}
```

最大一个点跑了 $728$ ms，空间花了 $2.20$ MB~~，非常优秀~~。
